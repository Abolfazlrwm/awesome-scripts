# 🧮 پروژه‌های تمرینی C (C Practice Projects)

> 📬 **Telegram:** [@Abolfazl_rwm](https://t.me/Abolfazl_rwm)

دو تمرین کلاسیک زبان C برای یادگیری رشته‌ها و اعداد بزرگ — همراه فایل پروژه‌ی Code::Blocks برای هر کدام:

## 📦 پروژه‌ها

### ۱) hello-string-check
دو رشته می‌گیرد و با `strstr` بررسی می‌کند رشته‌ی دوم داخل اولی هست یا نه (`YES`/`NO`) — تمرین `fgets`، `strcspn` و جست‌وجوی زیررشته.

### ۲) bignumber-math
محاسبات روی اعداد تا ۵۰ رقم (`MAX_DIGITS 50`) با ذخیره‌ی رقم‌به‌رقم در آرایه — شامل تابع `reverse` و جمع/عملیات دستی بدون کتابخانه‌ی bigint.

## 🚀 کامپایل و اجرا

```bash
gcc hello-string-check/main.c -o hello && ./hello
gcc bignumber-math/main.c     -o bignum && ./bignum
```

فایل‌های `.cbp` را هم می‌توانی مستقیم در Code::Blocks باز کنی. فایل‌های باینری خروجی (`.exe`/`.o`) برای سبک‌ماندن مخزن کامیت نشده‌اند.
