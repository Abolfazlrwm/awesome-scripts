# 🖥 مانیتور سیستم | System Monitor (PyQt6)

یک اپلیکیشن دسکتاپ سبک با PyQt6 برای مشاهده لحظه‌ای مصرف CPU، RAM و دیسک، به همراه یک تب اطلاعات کلی سیستم.

![Python](https://img.shields.io/badge/Python-3.8%2B-3776AB.svg)
![PyQt6](https://img.shields.io/badge/PyQt6-GUI-41CD52.svg)
![Cross Platform](https://img.shields.io/badge/platform-Windows%20%7C%20macOS%20%7C%20Linux-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green)

## ✨ امکانات

- 📊 نمایش زنده و آپدیت‌شونده (هر ۱ ثانیه) درصد مصرف CPU، RAM و Disk
- ℹ️ تب اطلاعات سیستم: سیستم‌عامل، پردازنده، معماری، هاست‌نیم و مقدار کل RAM
- 🖥 رابط کاربری تب‌دار و ساده با PyQt6
- 🌍 کاملاً چندسکویی: ویندوز، مک و لینوکس (مسیر دیسک به‌صورت خودکار تشخیص داده می‌شود)

## ⚙️ نصب و راه‌اندازی

```bash
pip install -r requirements.txt
python system_monitor.py
```
