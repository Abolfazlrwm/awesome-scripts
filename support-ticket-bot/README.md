# 🎫 ربات پشتیبانی و تیکتینگ (Support Ticket Bot)

پیام‌های پیوی کاربران رو به یک گروه پشتیبانی اختصاصی فوروارد می‌کنه؛ هر عضو تیم پشتیبانی فقط با ریپلای کردن روی همون پیام، جواب مستقیم به کاربر می‌رسه — بدون اینکه کاربر بفهمه از طرف چه اکانتی جواب گرفته.

![python-telegram-bot](https://img.shields.io/badge/python--telegram--bot-20+-2CA5E0.svg)

## ✨ امکانات

- 📩 فوروارد خودکار پیام‌های پیوی کاربر به گروه پشتیبانی، همراه با اطلاعات کاربر (نام، یوزرنیم، آیدی عددی)
- 💬 پاسخ تیم پشتیبانی با ریپلای ساده — ربات خودکار جواب رو برای کاربر اصلی می‌فرسته
- 🎫 هر گفتگو یک شماره‌ی تیکت اختصاصی دارد
- 🔒 بستن تیکت با دستور `/close` (توسط کاربر) یا دکمه‌ی شیشه‌ای (توسط تیم پشتیبانی)
- 📊 دستور `/stats` برای دیدن تعداد تیکت‌های باز/بسته (فقط داخل گروه پشتیبانی)
- 💾 پایگاه‌داده‌ی SQLite داخلی — بدون نیاز به تنظیم جداگانه

## 📋 پیش‌نیازها

- Python نسخه‌ی ۳.۸ یا بالاتر
- یک گروه تلگرامی که به‌عنوان «گروه پشتیبانی» استفاده می‌شود

## ⚙️ نصب و راه‌اندازی

### گام ۱: نصب وابستگی‌ها
```bash
pip install -r requirements.txt
```

### گام ۲: ساخت گروه پشتیبانی و پیدا کردن آیدی آن
1. یک گروه بساز و ربات را به آن اضافه کن
2. یک پیام از آن گروه را به [@userinfobot](https://t.me/userinfobot) فوروارد کن تا آیدی عددی گروه (چیزی شبیه `-1001234567890`) را بگیری

### گام ۳: تنظیمات اولیه
فایل `bot.py` را باز کن و این مقادیر را جایگزین کن:

| متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | توکن ربات از [@BotFather](https://t.me/BotFather) |
| `SUPPORT_GROUP_ID` | آیدی عددی گروه پشتیبانی (با علامت منفی) |

### گام ۴: اجرا
```bash
python bot.py
```

## 📖 نحوه‌ی کار

1. کاربر برای ربات پیام می‌فرستد (پیوی)
2. ربات پیام را با اطلاعات کاربر به گروه پشتیبانی می‌فرستد
3. هر عضو گروه پشتیبانی روی همان پیام **ریپلای** می‌زند
4. ربات خودکار جواب را برای کاربر اصلی ارسال می‌کند
