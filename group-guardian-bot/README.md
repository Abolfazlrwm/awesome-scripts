# 🛡️ ربات نگهبان گروه (Group Guardian Bot)

ربات مدیریت و ضدهرزنامه‌ی گروه تلگرام — خوش‌آمدگویی خودکار همراه با کپچای ورود، فیلتر کلمات ممنوعه، تشخیص و مهار اسپم، سیستم اخطار و مجموعه‌ی کاملی از دستورات مدیریتی.

![node-telegram-bot-api](https://img.shields.io/badge/node--telegram--bot--api-0.66-2CA5E0.svg)
![License](https://img.shields.io/badge/license-MIT-green)

## ✨ امکانات

- 👋 پیام خوش‌آمدگویی سفارشی برای اعضای جدید
- 🔐 کپچای ورود: عضو جدید تا وقتی دکمه‌ی تأیید رو نزنه حق پیام دادن نداره؛ اگه دیر کنه خودکار اخراج می‌شه
- 🌊 ضدهرزنامه (Anti-flood): اگه کسی خیلی سریع پشت‌سرهم پیام بده، خودکار میوت می‌شه
- 🚫 فیلتر کلمات ممنوعه با قابلیت افزودن/حذف از داخل ربات
- ⚠️ سیستم اخطار: بعد از رسیدن به سقف اخطار، کاربر خودکار میوت می‌شه
- 🛠 دستورات کامل مدیریتی: میوت، رفع میوت، اخراج، بن، آنبن، اخطار
- 📜 دستور `/rules` برای نمایش قوانین گروه (قابل تنظیم توسط ادمین)
- 💾 ذخیره‌سازی تنظیمات هر گروه به‌صورت جداگانه (فایل JSON، بدون نیاز به دیتابیس خارجی)

## 📋 پیش‌نیازها

- Node.js نسخه‌ی ۱۸ یا بالاتر
- ربات باید در گروه **ادمین** باشد و دسترسی «محدود کردن اعضا» (Restrict Members) را داشته باشد

## ⚙️ نصب و راه‌اندازی

### گام ۱: نصب وابستگی‌ها
```bash
npm install
```

### گام ۲: تنظیمات اولیه
فایل `bot.js` را باز کن و مقادیر زیر را (نزدیک ابتدای فایل) جایگزین کن:

| متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | توکن ربات از [@BotFather](https://t.me/BotFather) |
| `OWNER_ID` | آیدی عددی خودت از [@userinfobot](https://t.me/userinfobot) |

می‌توانی مقادیر دیگری مثل `CAPTCHA_TIMEOUT_SECONDS`, `FLOOD_MESSAGE_LIMIT`, `MAX_WARNINGS` را هم بر اساس نیازت تنظیم کنی.

### گام ۳: اجرا
```bash
npm start
```
یا:
```bash
node bot.js
```

### گام ۴: افزودن به گروه
ربات را به گروه اضافه کن و **ادمین** کن (حتماً دسترسی «Ban users» و «Restrict members» را فعال بگذار).

## 📖 دستورات

از داخل ربات دستور `/help` را بزن تا لیست کامل دستورات (بر اساس نقش کاربر) نمایش داده شود.
