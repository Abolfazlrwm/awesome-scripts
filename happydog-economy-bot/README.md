# 🐕 هاپ‌داگ | ربات اقتصادی و سرگرمی گروهی

کامل‌ترین ربات اقتصادی/بازی گروهی برای تلگرام — از هاپ‌زدن ساده تا مدیریت شهر، انتخابات شهرداری و حتی رهبری ملی! کاربران با هاپ‌زدن پوینت جمع می‌کنند، سگ می‌خرند، ماهیگیری می‌کنند، کارخانه می‌سازند و در اقتصاد گروه شرکت می‌کنند.

## ✨ امکانات

### 🎮 هسته‌ی بازی
- 🐾 هاپ‌زدن و جمع‌آوری پوینت با کول‌داون قابل تنظیم
- ⭐ سیستم سطح‌بندی (تا سطح ۱۰۰۰!)
- 🐕 خرید و پرورش سگ با سطح و مقام (از سگ خیابانی تا سگ جاودان)
- 🎣 سیستم ماهیگیری: خرید و ارتقای قلاب، صید استخوان‌های کمیاب تا افسانه‌ای
- 🍖 تغذیه‌ی سگ با استخوان‌های صیدشده

### 💰 اقتصاد
- 🏭 کارخانه: تولید محصول، فروش در بازار پویا (قیمت‌های در حال تغییر)
- 🏦 بانک با سود روزانه و شماره حساب اختصاصی
- 🛒 بازار کاربر به کاربر (خرید و فروش آزاد بین بازیکنان)
- 💸 انتقال پوینت بین کاربران
- 🎁 سیستم دعوت دوستان با پاداش دوطرفه

### 🎲 سرگرمی و ریسک
- 🎰 لاتاری، تاس، اسلات، گردونه‌ی شانس، بازی XO
- 🥷 سیستم قاچاق (ریسک بالا / پاداش بالا)
- ⛓ زندان: رأی‌گیری گروهی برای زندانی کردن، امکان فرار یا کار در زندان

### 🏙 حکمرانی گروهی
- 🏰 سیستم شهر: خزانه‌ی مشترک، سطح شهر، باف روی هاپ/ماهیگیری/کارخانه
- 🚨 بحران‌های شهری تصادفی که شهردار باید مدیریت کند
- 🗳 انتخابات شهردار با وعده‌های انتخاباتی و رأی‌گیری
- 📢 اعتراض و عزل شهردار توسط اهالی گروه
- 🏗 پروژه‌های شهری و قراردادهای صنعتی/بانکی/رفاهی
- 👑 سیستم رهبری ملی: فرمان ملی، قانون‌گذاری، شورای وزیران، رویداد ملی، وضعیت اضطراری

### 🎛 مدیریت
- 🛠 پنل ادمین کامل (ریست کاربران، مدیریت جوین اجباری و ...)
- 👤 پروفایل کامل هر کاربر با آمار، رتبه و مدال

> ℹ️ بعضی از دستورات ممکن است هنوز در حال توسعه/رفع باگ باشند.

## 📋 پیش‌نیازها

- Python نسخه‌ی ۳.۸ یا بالاتر
- کتابخانه‌های `python-telegram-bot` و `pytz`

## ⚙️ نصب و راه‌اندازی

### گام ۱: نصب وابستگی‌ها
```bash
pip install -r requirements.txt

### گام ۲: تنظیمات اولیه
فایل `bot.py` را باز کن و این مقادیر را نزدیک ابتدای فایل تنظیم کن:

| متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | توکن ربات از [@BotFather](https://t.me/BotFather) |
| `BOT_USERNAME` | یوزرنیم ربات (بدون @) |
| `ADMIN_IDS` | لیست آیدی عددی مدیران، مثل `[123456789]` |
| `FORCE_JOIN_CHANNEL` | یوزرنیم کانال جوین اجباری |
| `FORCE_JOIN_CHANNEL_LINK` | لینک دعوت کانال |
| `FORCE_JOIN_CHANNEL_NAME` | نام نمایشی کانال |

### گام ۳: اجرا
```bash
python bot.py

پایگاه‌داده (`happy_bot.db`) و تمام جداول به‌صورت خودکار ساخته می‌شوند.
