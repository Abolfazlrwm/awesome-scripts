# 🎯 ربات کوییز و مسابقه (Quiz & Trivia Bot)

سوالات چهارگزینه‌ای توی گروه می‌پرسه، اولین نفری که جواب درست بده امتیاز می‌گیره، و یک لیدربورد کامل برای هر گروه نگه می‌داره.

![Java](https://img.shields.io/badge/Java-21+-ED8B00.svg)
![No dependencies](https://img.shields.io/badge/dependencies-none-success.svg)
![License](https://img.shields.io/badge/license-MIT-green)

## ✨ امکانات

- ❓ مسابقه‌ی ۵ سوالی با دکمه‌های شیشه‌ای (چهار گزینه)
- 🏆 لیدربورد اختصاصی برای هر گروه
- ➕ افزودن سوال جدید توسط ادمین، مستقیم از داخل چت
- 📁 بانک سوالات پیش‌فرض همراه پروژه (قابل ویرایش با فایل متنی ساده)
- 🧩 **بدون هیچ کتابخانه‌ی خارجی** — فقط با کتابخانه‌ی استاندارد جاوا (`java.net.http`) نوشته شده؛ نیازی به Maven/Gradle نیست

## 📋 پیش‌نیازها

- JDK نسخه‌ی ۱۷ یا بالاتر (برای `java.net.http.HttpClient` و `record`)

## ⚙️ نصب و راه‌اندازی

### گام ۱: تنظیمات اولیه
فایل `src/Main.java` را باز کن و این مقادیر را جایگزین کن:

| ثابت | توضیح |
|---|---|
| `BOT_TOKEN` | توکن ربات از [@BotFather](https://t.me/BotFather) |
| `ADMIN_IDS` | آیدی عددی مدیرانی که اجازه‌ی افزودن سوال دارند |

### گام ۲: کامپایل
```bash
javac -d out src/*.java
```

### گام ۳: اجرا
```bash
cd out
java Main
```

فایل‌های `questions.txt` (بانک سوالات) و `scores.json` (امتیازها) به‌صورت خودکار در پوشه‌ی اجرا ساخته می‌شوند.

## 📖 فرمت افزودن سوال جدید

از داخل ربات (فقط ادمین):
```
/addquestion سوال|گزینه۱|گزینه۲|گزینه۳|گزینه۴|ایندکس‌درست
```
مثال:
```
/addquestion پایتخت فرانسه کجاست؟|لندن|پاریس|رم|برلین|1
```
(ایندکس از ۰ شروع می‌شود؛ در این مثال گزینه‌ی دوم یعنی «پاریس» درست است.)

می‌توانی فایل `questions.txt` را هم مستقیم با هر ادیتوری باز کنی و چند سوال با هم اضافه کنی (هر خط یک سوال با همین فرمت).

## 📖 دستورات

| دستور | توضیح |
|---|---|
| `/quiz` | شروع یک دور مسابقه (۵ سوال) |
| `/leaderboard` | نمایش برترین‌های این گروه |
| `/addquestion ...` | (فقط ادمین) افزودن سوال جدید |
