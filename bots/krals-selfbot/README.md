# 🐺 سلف‌بات کرالز (Krals Selfbot)

> 📬 **Telegram:** [@Abolfazl_rwm](https://t.me/Abolfazl_rwm)

پنل سلف Pyrogram با چند کلاینت: `Krals.py` هسته‌ی اصلی روی اکانت خودت، `Krals2.py` کلاینت دوم و `parsa.py` ماژول جانبی — با تنظیمات مرکزی در `config.py` (منطقه‌ی زمانی تهران، لیست ادمین‌ها، اجازه‌ی افزودن ادمین).

## ✨ امکانات

- 👥 چند ادمین با سطوح دسترسی (`can_add_admin`)
- 🕐 پشتیبانی تایم‌زون ایران برای کارهای زمان‌دار
- 🔧 استفاده از raw functions (مدیریت عضویت کانال‌ها و ...)
- 🧩 معماری ماژولار — کلاینت دوم برای کارهای موازی

## 📋 پیش‌نیازها

- Python ۳.۸+ و وابستگی‌های `requirements.txt`
- ⚠️ یوزربات — فقط روی اکانت خودت و با مسئولیت خودت.

## ⚙️ نصب و راه‌اندازی

### گام ۱: پیکربندی
فایل `config.py`: مقدار `api_id` و `api_hash` اکانت خودت را بگذارید و `admins` را با آیدی عددی خودت تنظیم کنید.

### گام ۲: اجرا
```bash
pip install -r requirements.txt
python Krals.py
```
