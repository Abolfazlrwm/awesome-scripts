# 🏷 ابزار نام و یوزرنیم کانال (Channel Username Tool)

> 📬 **Telegram:** [@Abolfazl_rwm](https://t.me/Abolfazl_rwm)

اسکریپت Telethon برای ساخت کانال و تغییر یوزرنیم به‌صورت گروهی: لیست نام‌ها/یوزرنیم‌ها را می‌دهید و ربات به‌ترتیب کانال می‌سازد، یوزرنیم می‌گیرد و در صورت اشغال بودن ادامه می‌دهد.

## ✨ امکانات

- ساخت خودکار کانال (`CreateChannelRequest`)
- تغییر یوزرنیم با مدیریت خطاهای FloodWait و اشغال بودن
- دستورات فارسی: شروع، توقف، افزودن، حذف، لیست
- اجرای زمان‌بندی‌شده عملیات

## 📋 پیش‌نیازها

- Python ۳.۸+ و `pip install telethon`

## ⚙️ نصب و راه‌اندازی

### گام ۱: پیکربندی
1. api_id/api_hash اکانت را در `taggir.py` وارد کنید؛ لیست‌ها را با دستورات داخل ربات مدیریت کنید.

### گام ۲: اجرا
```bash
python taggir.py
```
