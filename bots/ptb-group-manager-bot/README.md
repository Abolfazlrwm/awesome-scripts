# 👮 مدیریت گروه کامل (PTB) (PTB Group Manager Bot)

> 📬 **Telegram:** [@Abolfazl_rwm](https://t.me/Abolfazl_rwm)

ربات مدیریت گروه بر پایه‌ی python-telegram-bot با فایل `handlers.py` بیش از ۱۱۰ هزار کاراکتر: پنل ادمین، فیلترها، سنجش سن اکانت (`account_age.py`)، نرخ ارز داخلی و دیتابیس ساختاریافته.

## ✨ امکانات

- پنل ادمین گسترده با کیبوردهای شیشه‌ای
- فیلتر پیام و مدیریت مجوزها
- بررسی سن اکانت اعضا ضد-اسپم
- ماژول نرخ ارز داخلی
- دیتابیس ماژولار (`database.py`)

## 📋 پیش‌نیازها

- Python ۳.۸+ و `pip install -r requirements.txt`

## ⚙️ نصب و راه‌اندازی

### گام ۱: پیکربندی
1. `config.py` را پر کنید (توکن، ادمین‌ها، کانال‌ها)؛ نمونه در `env.example` هست.

### گام ۲: اجرا
```bash
python bot.py
```
