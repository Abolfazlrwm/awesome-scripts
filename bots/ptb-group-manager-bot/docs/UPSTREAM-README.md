# گروپ منیجر - ربات مدیریت گروه تلگرام



ربات پیشرفته مدیریت گروه تلگرام با قابلیت‌های متنوع مدیریتی، ضد اسپم، نمایش نرخ ارز و طلا، و طراحی شیشه‌ای.

## 🌟 قابلیت‌ها

### 🛡 مدیریت گروه
- **مدیریت کاربران**: بن، میوت، اخطار، رفع محدودیت
- **تنظیمات امنیتی**: ضد لینک، ضد فحش، ضد فوروارد
- **مدیریت محتوا**: حذف پیام‌های نامناسب، شناسایی اسپم
- **مدیریت ادمین**: ترفیع، عزل، نمایش لیست ادمین‌ها

### 📊 آمار و اطلاعات
- **آمار گروه**: تعداد پیام‌ها، کاربران فعال، اخطارها
- **اطلاعات کاربر**: نمایش اطلاعات کاربر، تاریخ عضویت، فعالیت
- **رتبه‌بندی**: نمایش کاربران برتر و فعال گروه

### 💰 اطلاعات مالی
- **نرخ ارز**: نمایش قیمت انواع ارزها (دلار، یورو، پوند و...)
- **قیمت طلا و سکه**: نمایش قیمت انواع سکه و طلا
- **ارز دیجیتال**: نمایش قیمت بیت‌کوین و سایر ارزهای دیجیتال

### 👮 پنل ادمین
- **پنل مدیریتی**: تنظیمات گروه، مدیریت کاربران، آمار
- **دستورات فارسی**: پشتیبانی از دستورات به زبان فارسی
- **قوانین گروه**: تنظیم و نمایش قوانین گروه

### 🎨 طراحی
- **رابط کاربری شیشه‌ای**: طراحی زیبا و کاربرپسند
- **شخصی‌سازی**: امکان تغییر پیام خوشامدگویی و قالب‌ها
- **نمایش فارسی**: تاریخ شمسی، ساعت ایران، نوتیفیکیشن‌های فارسی

</div>

## 📝 نصب و راه‌اندازی

<div dir="rtl">

### پیش‌نیازها
- Python 3.7+
- پایتون-تلگرام-بات
- SQLite3
- جدتایم (jdatetime)
- پایتز (pytz)
- requests

### مراحل نصب

1. کلون کردن مخزن:
```bash
git clone https://github.com/yourusername/group-manager-bot.git
cd group-manager-bot
```

2. نصب وابستگی‌ها:
```bash
pip install -r requirements.txt
```

3. تنظیم فایل پیکربندی:
```bash
cp config.py.example config.py
```
و سپس ویرایش فایل `config.py` با تنظیمات و توکن ربات خود

4. اجرای ربات:
```bash
python bot.py
```

</div>

## 🚀 نحوه استفاده

<div dir="rtl">

### دستورات اصلی
- `/start` - شروع کار با ربات
- `/help` - نمایش راهنمای ربات
- `/admin` - دسترسی به پنل ادمین
- `/ban` - حذف کاربر از گروه
- `/mute` - بی‌صدا کردن کاربر
- `/warn` - اخطار به کاربر
- `/currency` یا `/arz` - نمایش قیمت ارزها
- `/crypto` یا "رمزارز" - نمایش قیمت ارزهای دیجیتال
- `/gold` یا "طلا" - نمایش قیمت طلا و سکه
- `/top` - نمایش کاربران فعال گروه

### پنل ادمین
برای دسترسی به پنل ادمین، دستور `/admin` یا "پنل" را ارسال کنید. در این پنل می‌توانید:
- تنظیمات گروه را تغییر دهید
- آمار گروه را مشاهده کنید
- دستورات سفارشی اضافه کنید
- قوانین گروه را تنظیم کنید
- مدیریت ادمین‌ها را انجام دهید
