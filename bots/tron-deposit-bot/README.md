# 💠 درگاه ترون و کیف پول (Tron Deposit Bot)

> 📬 **Telegram:** [@Abolfazl_rwm](https://t.me/Abolfazl_rwm)

ربات فروشگاهی با درگاه شبکه‌ی ترون (tronpy): واریز TRX با تولید کیف پول اختصاصی، درخواست برداشت ترون و تومان، پنل ادمین شامل افزایش/کاهش موجودی، ثبت تبلیغ، نفرات برتر و حسابرس.

## ✨ امکانات

- کیف پول اختصاصی ترون برای هر کاربر
- واریز/برداشت TRX و تومان با تایید ادمین
- پنل ادمین کامل (موجودی، تبلیغ، آمار، حسابرس)
- عضویت اجباری کانال
- دیتابیس SQLite داخلی

## 📋 پیش‌نیازها

- Python ۳.۸+ و `pip install pyrogram tgcrypto tronpy`

## ⚙️ نصب و راه‌اندازی

### گام ۱: پیکربندی
1. api_id/api_hash، توکن و کلید کیف پول ادمین را طبق فایل تنظیم کنید؛ آدرس کیف پول سرد را در تنظیمات بگذارید.

### گام ۲: اجرا
```bash
python main.py
```
