# 🌩 مدیریت کلودفلر از تلگرام (Cloudflare Manager Bot)

> 📬 **Telegram:** [@Abolfazl_rwm](https://t.me/Abolfazl_rwm)

ربات مدیریتی Cloudflare بر پایه‌ی python-telegram-bot؛ با توکن API کلودفلر به اکانت وصل می‌شود و عملیات مدیریتی را از داخل تلگرام با دکمه‌های شیشه‌ای انجام می‌دهد.

## ✨ امکانات

- اتصال به REST API کلودفلر
- پنل دکمه‌ای شیشه‌ای در تلگرام
- مناسب مدیریت DNS و رکوردها
- لاگ‌گیری استاندارد

## 📋 پیش‌نیازها

- Python ۳.۸+ و `pip install python-telegram-bot requests`

## ⚙️ نصب و راه‌اندازی

### گام ۱: پیکربندی
1. `TELEGRAM_BOT_TOKEN` را از BotFather و `CLOUDFLARE_API_TOKEN` را از داشبورد کلودفلر وارد کنید (مقدار فعلی placeholder است).

### گام ۲: اجرا
```bash
python cloudbot.py
```
