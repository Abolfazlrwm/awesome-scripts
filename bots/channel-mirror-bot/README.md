# 🪞 آینه‌ی کانال‌ها (Channel Mirror Bot)

> 📬 **Telegram:** [@Abolfazl_rwm](https://t.me/Abolfazl_rwm)

ربات PHP که پست‌های کانال‌های مبدأ تعریف‌شده را به‌صورت خودکار به کانال مقصد منتقل می‌کند؛ لیست مبدأها داخل کد و قابل ویرایش است — برای آرشیو یا بازنشر خودکار کانال‌ها ساخته شده.

## ✨ امکانات

- بازنشر خودکار پست از چند کانال مبدأ
- لیست مبدأ به‌صورت آرایه در کد
- فیلتر بر اساس نوع محتوا
- سبک و تک‌فایلی

## 📋 پیش‌نیازها

- هاست PHP ۷.۴+
