# 🎛 مدیریت ریموت اکانت‌ها (Remote Admin Bot)

> 📬 **Telegram:** [@Abolfazl_rwm](https://t.me/Abolfazl_rwm)

ربات Pyrogram با توکن بات + API اکانت که از راه دور به اکانت‌های متصل دستور می‌دهد؛ فایل‌ها در پوشه‌های `files/` و `accounts/` مدیریت می‌شوند و فقط ادمین تعریف‌شده اجازه‌ی استفاده دارد.

## ✨ امکانات

- کنترل ریموت چند اکانت از یک ربات
- مدیریت فایل بین اکانت‌ها (files/ و accounts/)
- دسترسی محدود به ادمین
- استفاده از raw API تلگرام

## 📋 پیش‌نیازها

- Python ۳.۸+ و `pip install pyrogram tgcrypto`

## ⚙️ نصب و راه‌اندازی

### گام ۱: پیکربندی
1. api_id/api_hash و توکن ربات را در `remote.py` وارد کنید (مقدارهای فعلی placeholder هستند) و آیدی ادمین را بگذارید.

### گام ۲: اجرا
```bash
python remote.py
```
