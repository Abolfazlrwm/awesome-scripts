# 🧲 کپی‌کن پست HxD (HxD Post Copier)

> 📬 **Telegram:** [@Abolfazl_rwm](https://t.me/Abolfazl_rwm)

برادر کوچک‌ترِ سوپرتبچی — همان خانواده‌ی Pyrogram + APScheduler: کپی خودکار پست‌های کانال مبدأ به مقصدها با تایمر، در نسخه‌ای جمع‌وجورتر که ادمین اول را در اولین اجرا می‌پرسد.

## ✨ امکانات

- 📋 کپی خودکار پست‌ها به دیالوگ‌ها و کانال‌های مقصد
- ⏱ تایمرهای گروه/کانال جداگانه با APScheduler
- 🧑‍💻 ست‌آپ تعاملی — `Owner` در اولین اجرا با `input` گرفته می‌شود
- 🪶 تک‌فایل و سبک

## 📋 پیش‌نیازها

- Python ۳.۸+، `pip install pyrogram apscheduler`
- ⚠️ یوزربات — مسئولیت اجرا با خودت است.

## ⚙️ نصب و راه‌اندازی

### گام ۱: پیکربندی
در `HxD.py` مقدار `api_id` و `api_hash` خودت را بگذارید (جای‌گذاری‌شده با `0` و `''`).

### گام ۲: اجرا
```bash
python HxD.py
```
آیدی عددی ادمین اول را وارد کنید؛ مبدأ/مقصد و تایمرها با دستورات ادمین تنظیم می‌شوند.
