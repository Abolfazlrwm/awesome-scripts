# 🖤 یوزربات BlackDiamond (Lua) (BlackDiamond Lua Userbot)

> 📬 **Telegram:** [@Abolfazl_rwm](https://t.me/Abolfazl_rwm)

یوزربات Lua روی موتور tdlua: هسته‌ی `Bot.lua` با سطوح دسترسی (sudo/owner/mod)، بن گلوبال، فال و ابزارهای متنوع؛ کتابخانه‌های جانبی در `libs/` و راهنمای نصب فارسی داخل سورس — باینری `tdlua.so` باید جداگانه ساخته/دریافت شود.

## ✨ امکانات

- موتور tdlua با Lua 5.3
- سطوح دسترسی کامل (FullSudo/Sudo/Owner/Mod)
- بن گلوبال و مدیریت کاربران
- کتابخانه‌های جانبی (redis، JSON، jdate، …)
- راهنمای نصب فارسی در `راهنما ران.txt`

## 📋 پیش‌نیازها

- Linux + Lua 5.3 + redis + ساخت `tdlua.so` طبق راهنما (باینری از مخزن حذف شده)

## ⚙️ نصب و راه‌اندازی

### گام ۱: پیکربندی
1. تنظیمات (api_id/api_hash و نام بات) در redis ذخیره می‌شود؛ طبق `راهنما ران.txt` پیش بروید و سپس اجرا کنید.

### گام ۲: اجرا
```bash
lua5.3 Run.lua <bot-name>
```
