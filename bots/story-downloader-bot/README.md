# 📸 دانلودر استوری تلگرام (Story Downloader Bot)

> 📬 **Telegram:** [@Abolfazl_rwm](https://t.me/Abolfazl_rwm)

ربات Pyrogram که **استوری‌های تلگرام** را دانلود و ارسال می‌کند — لینک یا یوزرنیم استوری را بده و مدیا را بگیر؛ لیست کانال‌های اجباری و ادمین ارشد (Sudo) هم دارد.

## ✨ امکانات

- 📥 دانلود استوری کاربران و ارسال در چت
- 👑 سودو/ادمین ارشد + لیست کانال‌های عضویت اجباری
- 🧩 کلاس `Config` مرتب — همه‌ی تنظیمات یک‌جا
- 🪶 سبک و تک‌فایل

## 📋 پیش‌نیازها

- Python ۳.۸+ و `pip install pyrogram requests`

## ⚙️ نصب و راه‌اندازی

### گام ۱: پیکربندی
در `StoryTelegramDL.py` بخش `Config` را پر کنید: `API_KEY` (توکن ربات از BotFather)، `API_ID`/`API_HASH` از [my.telegram.org](https://my.telegram.org)، `SUDO` و `CHANNLS`.

### گام ۲: اجرا
```bash
python StoryTelegramDL.py
```
