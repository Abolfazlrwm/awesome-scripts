# ☎️ خرید شماره از vak-sms (Vak SMS Bot)

> 📬 **Telegram:** [@Abolfazl_rwm](https://t.me/Abolfazl_rwm)

ربات PHP متصل به وب‌سرویس vak-sms برای خرید و مدیریت شماره‌های مجازی: دریافت شماره، خواندن پیامک OTP و لغو سفارش — کلیدهای سرویس placeholder شده‌اند.

## ✨ امکانات

- اتصال به وب‌سرویس vak-sms
- دریافت شماره و پیامک OTP
- لغو و تمدید سفارش
- پنل ادمین
- امنیت وب‌هوک
