# 🤫 ربات نجوا در گروه (Whisper Group Bot)

> 📬 **Telegram:** [@Abolfazl_rwm](https://t.me/Abolfazl_rwm)

ربات نجوا برای گروه‌ها: کاربر با فرمان مشخص پیام خصوصی می‌فرستد و گیرنده فقط خودش آن را می‌بیند؛ هر پیام شناسه‌ی یکتا (UUID) و گزارش‌گیری دارد — با dotenv و تنظیمات تمیز.

## ✨ امکانات

- پیام خصوصی داخل گروه (نجوا)
- شناسه یکتا برای هر نجوا
- گزارش و آمار ارسال
- تنظیمات با `.env`
- پاک‌سازی خودکار پیام‌ها

## 📋 پیش‌نیازها

- Python ۳.۸+ و `pip install python-dotenv` (طبق requirements سورس)

## ⚙️ نصب و راه‌اندازی

### گام ۱: پیکربندی
1. فایل `.env` را بر اساس نمونه بسازید و توکن را بگذارید.

### گام ۲: اجرا
```bash
python bot.py
```
