# ربات نجوا (Whisper Bot)

ربات نجوا یک ربات تلگرام برای ارسال پیام خصوصی (نجوا) در گروه‌هاست که امکانات حرفه‌ای و ظاهر زیبا دارد.

## امکانات اصلی
- ارسال نجوا (پیام خصوصی) در گروه‌ها
- تم‌های متنوع (۶ مدل مختلف)
- ارسال نجوا با تایمر و حذف خودکار
- مشاهده آمار و تاریخچه پیام‌ها
- تنظیمات شخصی‌سازی (اعلان، حذف خودکار، تم و ...)
- ارسال نجوا به کاربر خاص با @username
- امنیت و رمزنگاری پیام‌ها
- رابط کاربری حرفه‌ای و دکمه‌های تعاملی

## نصب و راه‌اندازی

۱. ابتدا پکیج‌های مورد نیاز را نصب کنید:

```
pip install -r requirements.txt
```

۲. توکن ربات تلگرام را در فایل `.env` یا به صورت مستقیم در کد قرار دهید.

۳. ربات را اجرا کنید:

```
python bot.py
```

## آموزش استفاده

- برای ارسال نجوا، ربات را در گروه تگ کنید و پیام خود را بنویسید.
- برای ارسال نجوا به کاربر خاص، نام کاربری او را با @ در متن پیام وارد کنید.
- از منوی تنظیمات می‌توانید تم، اعلان و حذف خودکار را تغییر دهید.
- با دکمه‌های "آمار من" و "تاریخچه"، آمار و پیام‌های قبلی خود را ببینید.
