# 🎭 پروفایل ساز با Faker (Faker Profile Bot)

> 📬 **Telegram:** [@Abolfazl_rwm](https://t.me/Abolfazl_rwm)

اسکریپت Telethon با کتابخانه‌ی Faker فارسی: ساخت پروفایل تصادفی (نام، بیو)، عضویت در کانال‌ها و اینویت‌های مشخص و مدیریت چند اکانت به‌صورت هم‌زمان — برای راه‌اندازی اکانت‌های آزمایشی.

## ✨ امکانات

- پروفایل تصادفی فارسی با Faker
- عضویت خودکار در کانال/اینوایت
- به‌روزرسانی نام و بیو
- اجرای هم‌زمان چند اکانت
- مدیریت خطاهای تلگرام

## 📋 پیش‌نیازها

- Python ۳.۸+ و `pip install telethon faker`

## ⚙️ نصب و راه‌اندازی

### گام ۱: پیکربندی
1. api_id/api_hash هر اکانت را طبق فایل تنظیم وارد کنید و لیست کانال‌های هدف را بدهید.

### گام ۲: اجرا
```bash
python main.py
```
