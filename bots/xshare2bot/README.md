# 🔗 اشتراک‌گذار پست XShare2 (XShare2 Bot)

> 📬 **Telegram:** [@Abolfazl_rwm](https://t.me/Abolfazl_rwm)

پروژه‌ی متن‌باز devdasher برای ذخیره و اشتراک‌گذاری پست‌های تلگرام با PHP: ساخت لینک کوتاه برای هر پست، آمار بازدید و پنل مدیریت — با مستندات انگلیسی/فارسی و لایسنس خود پروژه (در `docs/` و `LICENCE`).

## ✨ امکانات

- ذخیره و اشتراک پست با لینک کوتاه
- شمارش بازدید هر لینک
- پنل مدیریت
- اسکیمای MySQL آماده
- مستندات دو زبانه‌ی اصلی حفظ شده

## 📋 پیش‌نیازها

- هاست PHP ۷.۴+ و MySQL (composer install برای وابستگی‌ها)

## ⚙️ نصب و راه‌اندازی

### گام ۱: پیکربندی
1. اطلاعات دیتابیس و توکن را در `config/` تنظیم کنید؛ جدول‌ها از `*.sql` ساخته می‌شوند.

### گام ۲: اجرا
```bash
composer install
php -S localhost:8000
```
