# 🤖 ربات XShare2Bot
ربات XShare2Bot یک ربات ساده و کاربردی برای ذخیره و اشتراک گذاری پست های تلگرام است که کد منبع آن با استفاده از کتابخانه [Nutgram](https://github.com/nutgram/nutgram) نوشته شده است و بسیار منعطف، ماژولار و تمیز است. کد منبع این ربات تحت مجوز MIT منتشر شده و استفاده از آن رایگان است. نسخه اولیه این کد منبع برای اهداف آموزشی ایجاد شده است و مسئولیت هرگونه سوء استفاده از آن بر خلاف قوانین کشور بر عهده کاربر است.

شما می توانید این کد منبع را با توجه به نیاز خود ویرایش و استفاده کنید.

ممکن است برخی از اشکالات در کد منبع وجود داشته باشد، اما ارزش آن را دارد که خودتان آن را برطرف کنید.

# 🛠️ نصب و راه اندازی
- پروژه رو کلون کنید: `git clone https://github.com/devdasher/xshare2bot`
- در مسیر پروژه، دستور مقابل رو برای نصب وابستگی ها (کتابخونه های دیگه) اجرا کنید: `composer install` (لازمه که [Composer](https://getcomposer.org) رو اول نصب کنید)
- یک دیتابیس با نام `xshare2bot` ایجاد کنید (در MySQL) و با collation (کالیشن) مقابل: utf8mb4_bin
- بعدش فایل `sql/xshare2bot.sql` رو به دیتبایس خودتون ایمپورت کنید
- اطلاعات ربات و دیتابیس خودتون رو در فایل `config/config.php` قرار بدید (یادتون باشه که آیدی عددی اکانت تلگرام تون رو به عنوان ادمین قرار بدید حتما)
- حالا با دستور مقابل در ترمینال، میتونید ربات خودتون رو ران کنید `php index.php`, این ربات شمارو در حالت LongPolling ران میکنه
- اما اگر خواستید از حالت Webhook استفاده کنید, این تیکه کد رو از حالت کامنت دربیارید: `$bot->setRunningMode($webhook);` در فایل `index.php` در خط 39. بعدش میتونید رو فایل مذکور ست وب هوک انجام بدید
