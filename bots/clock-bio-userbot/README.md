# 🕰 ساعت زنده در بیو (Clock Bio Userbot)

> 📬 **Telegram:** [@Abolfazl_rwm](https://t.me/Abolfazl_rwm)

یوزربات Pyrogram که ساعت زنده را با قلب‌های رنگی در نام و بیوی اکانت نشان می‌دهد؛ هر دقیقه به‌صورت خودکار به‌روزرسانی می‌شود و لیست بیوهای دلخواه قابل تنظیم است.

## ✨ امکانات

- نمایش ساعت زنده در نام/بیو
- چرخه‌ی قلب‌های رنگی (۹ رنگ)
- لیست بیوهای آماده و قابل ویرایش
- به‌روزرسانی خودکار هر دقیقه

## 📋 پیش‌نیازها

- Python ۳.۸+ و `pip install pyrogram tgcrypto`

## ⚙️ نصب و راه‌اندازی

### گام ۱: پیکربندی
1. api_id/api_hash را در فایل تنظیم وارد کنید؛ لیست `biography` و `hearts` در `config.py` قابل ویرایش است.

### گام ۲: اجرا
```bash
python main.py
```
