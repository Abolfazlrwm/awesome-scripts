# 🏰 ثبت‌نام کلن Clash (Clash Clan Bot)

> 📬 **Telegram:** [@Abolfazl_rwm](https://t.me/Abolfazl_rwm)

ربات PHP ثبت‌نام اعضای کلن برای بازی‌های Clash Royale و Clash of Clans: پذیرش قوانین، بارگذاری تصویر پروفایل بازی و ذخیره‌ی اطلاعات هر کاربر در پوشه‌ی `data/<id>/`.

## ✨ امکانات

- پذیرش قوانین قبل از ثبت‌نام
- دریافت تصویر بازیکن مرحله‌به‌مرحله
- ذخیره‌سازی فایل‌محور per-user
- پشتیبانی دو حالت clashr و clashofc
- مدیریت state هر کاربر

## 📋 پیش‌نیازها

- هاست PHP ۷.۴+

## ⚙️ نصب و راه‌اندازی
