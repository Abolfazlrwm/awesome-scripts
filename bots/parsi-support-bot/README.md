# 📮 ربات پشتیبانی پارسی (Parsi Support Bot)

> 📬 **Telegram:** [@Abolfazl_rwm](https://t.me/Abolfazl_rwm)

ربات پشتیبانی PHP («پارسی ساپورتر»): کاربر پیام می‌فرستد، پیام به پشتیبانی می‌رسد و پاسخ مستقیم به کاربر برمی‌گردد؛ آمار، همگانی و روشن/خاموش‌کردن هم دارد.

## ✨ امکانات

- اتصال مستقیم کاربر به پشتیبانی
- پنل `/admin` با وضعیت ربات
- ارسال همگانی و مدیریت کاربران
- امنیت وب‌هوک با رنج IP تلگرام

## 📋 پیش‌نیازها
