# 📤 آپلودر فایل با پنل مدیریت (Python Uploader Bot)

> 📬 **Telegram:** [@Abolfazl_rwm](https://t.me/Abolfazl_rwm)

ربات آپلودر پایتونی (نسخه‌ی PTB از خانواده‌ی آپلودرهای مخزن): فایل‌های کاربران را ذخیره و بازنشر می‌کند و مدیر با پنل دکمه‌ای کپشن، متن استارت و پیام‌ها را کنترل می‌کند.

## ✨ امکانات

- دریافت و بازنشر فایل با کپشن دلخواه
- پنل مدیریت: کپشن، متن استارت، مدیریت پیام
- دکمه‌های شیشه‌ای و ورود به پنل از چت
- سبک و تک‌فایلی

## 📋 پیش‌نیازها

- Python ۳.۸+ و `pip install python-telegram-bot`

## ⚙️ نصب و راه‌اندازی

### گام ۱: پیکربندی
1. توکن ربات و آیدی ادمین را در `uploader.py` تنظیم کنید.

### گام ۲: اجرا
```bash
python uploader.py
```
