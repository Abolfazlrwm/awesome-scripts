# 🛡 محافظ نشست‌های اکانت (Anti-Login Guard Selfbot)

> 📬 **Telegram:** [@Abolfazl_rwm](https://t.me/Abolfazl_rwm)

ابزار کوچک ترکیبی Telethon/PTB با تمرکز بر امنیت اکانت: با دستور `antilogin on/off` نشست‌های فعال ناشناس را شناسایی و قطع می‌کند تا کسی نتواند به اکانت لاگین‌شده دسترسی داشته باشد.

## ✨ امکانات

- دستور `antilogin on` / `antilogin off`
- شناسایی و قطع نشست‌های ناشناس
- بخش بات PTB برای کنترل از راه دور
- کد کوتاه و قابل‌فهم

## 📋 پیش‌نیازها

- Python ۳.۸+ و `pip install telethon python-telegram-bot`

## ⚙️ نصب و راه‌اندازی

### گام ۱: پیکربندی
1. api_id/api_hash را از [my.telegram.org](https://my.telegram.org) و توکن ربات را از BotFather وارد کنید.

### گام ۲: اجرا
```bash
python bot.py
```
