# ☁️ IPهای سالم کلودفلر (Cloudflare IP Finder Bot)

> 📬 **Telegram:** [@Abolfazl_rwm](https://t.me/Abolfazl_rwm)

ربات PHP از @U3erZX که فهرست IPهای سالم کلودفلر را می‌گیرد (منبع به‌صورت base64 در کد) و به کاربر تحویل می‌دهد؛ برای کسانی که روی فیلترینگ و اتصال کار می‌کنند کاربردی است.

## ✨ امکانات

- استخراج خودکار لیست IP سالم
- خروجی مرتب با متن خوش‌آمد
- امنیت وب‌هوک با رنج IP تلگرام
- تک‌فایلی و بدون دیتابیس

## 📋 پیش‌نیازها

- هاست PHP ۷.۴+
