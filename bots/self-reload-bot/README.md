# 🔧 سلف با ری‌لود زنده (Self Reload Bot)

> 📬 **Telegram:** [@Abolfazl_rwm](https://t.me/Abolfazl_rwm)

سلف‌بات Pyrogram با **سیستم ری‌لود ماژول‌ها بدون ری‌استارت** (`importlib.reload`)، دانلود یوتیوب با pytube، مدیریت لیست «دشمن» و ابزارهای پروفایل — نصب آن هم طبق `docs/install-fa.txt` با دریافت api از @PyGetApi1Bot توضیح داده شده.

## ✨ امکانات

- ♻️ ری‌لود زنده‌ی ماژول‌ها (`reloads.py` + `importlib.reload`) — تغییرات بدون قطع سشن
- 🎬 دانلود از یوتیوب (pytube) و ارسال در چت
- 📒 مدیریت لیست Enemy در `data/Enemy.txt`
- 🖼 ابزارهای پروفایل (ست عکس پروفایل، نام و بیو)

## 📋 پیش‌نیازها

- Python ۳.۸+ و وابستگی‌های `requirements.txt`
- ⚠️ یوزربات — مسئولیت اجرا با خودت است.

## ⚙️ نصب و راه‌اندازی

### گام ۱: پیکربندی
مطابق `docs/install-fa.txt`، `api_id` و `api_hash` بگیر و در ابتدای `bot.py` بگذار.

### گام ۲: اجرا
```bash
pip install -r requirements.txt
python bot.py
```
