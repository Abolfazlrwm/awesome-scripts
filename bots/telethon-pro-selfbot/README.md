# 🧰 سلف حرفه‌ای Telethon (Telethon Pro Selfbot)

> 📬 **Telegram:** [@Abolfazl_rwm](https://t.me/Abolfazl_rwm)

سلف‌بات کامل Telethon با مجموعه‌ای از ابزارهای پروفایل و اکانت: مدیریت پروفایل، واکنش‌گذاری، اعلان اسکرین‌شات، تماس گروهی، زمان‌بندی با aiocron و پایش منابع سیستم با psutil.

## ✨ امکانات

- مدیریت کامل پروفایل (عکس، نام، بیو)
- واکنش و اعلان اسکرین‌شات با raw API
- ساخت تماس گروهی (CreateGroupCall)
- زمان‌بندی cron با aiocron
- پایش منابع با psutil و لاگ aiohttp

## 📋 پیش‌نیازها

- Python ۳.۸+ و `pip install telethon psutil pytz aiocron aiofiles aiohttp numpy`

## ⚙️ نصب و راه‌اندازی

1. api_id/api_hash را از [my.telegram.org](https://my.telegram.org) بگیرید و در فایل تنظیم کنید.

### گام ۲: اجرا
```bash
python self.py
```
