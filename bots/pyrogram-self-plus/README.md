- 🧠 اجرای کد آنلاین با `rextester_Api.py` (پایتون، C، جاوا و ...)

- 💬 اولین کامنت خودکار زیر پست‌ها + متن‌های خوش‌آمد دوزبانه
- 🔐 raw functions: ریست سشن‌ها، لیست بلاک، همه‌ی استیکرها و ...
- 💾 ذخیره‌ی تنظیمات فایل‌محور (`if_not_exist_creat`)

## 📋 پیش‌نیازها

- Python ۳.۸+ و وابستگی‌های `requirements.txt`
- ⚠️ یوزربات — روی اکانت خودت و با مسئولیت خودت.
