# 🧫 مجموعه APIهای عمومی (Public API Suite)

> 📬 **Telegram:** [@Abolfazl_rwm](https://t.me/Abolfazl_rwm)

مجموعه‌ای از APIهای آماده‌ی PHP: جستجوی دیجی‌کالا، OCR تصویر، وضعیت کرونا، ایمیل موقت، اینستاگرام، واترمارک، TextNow و… — هر سرویس یک فایل مستقل با خروجی JSON و نمونه‌های تصویری.

## ✨ امکانات

- جستجوی دیجی‌کالا (`api.php`)
- OCR و پردازش تصویر و واترمارک
- ایمیل موقت و TextNow
- وضعیت کرونا و ابزارهای متنوع
- تصاویر نمونه در `Photo/`

## 📋 پیش‌نیازها

- PHP ۷.۴+ با curl

## ⚙️ نصب و راه‌اندازی

### گام ۱: پیکربندی
1. هر فایل یک سرویس مستقل است؛ مستقیم روی هاست بگذارید و با پارامتر `?q=` یا مشابه صدا بزنید.

### گام ۲: اجرا
```bash
php -S localhost:8000
```
