# 🔐 قالب فرم ورود فارسی (Persian Login Form Template)

قالب آماده‌ی **فرم ورود فارسی/RTL** با فونت وزیرمتن و سورس SCSS کامل — هم CSS نهایی (`assets/css/styles.css`) هم فایل‌های SCSS ماژولار (`base`، `config`، `components`) برای شخصی‌سازی.

## ✨ امکانات

- 🎨 طراحی مینیمال با پس‌زمینه‌ی اختصاصی (`assets/img/login-bg.png`)
- 🔤 خانواده‌ی کامل فونت وزیرمتن (Thin تا Black + متغیر)
- 🧩 SCSS ماژولار: `_base`، `_variables`، `_login`، `_breakpoints`
- 📱 واکنش‌گرا با بریک‌پوینت‌های آماده

## 🚀 اجرا

`index.html` را در مرورگر باز کنید. برای تغییر استایل، SCSSها را ویرایش و دوباره کامپایل کنید (`sass assets/scss/styles.scss assets/css/styles.css`).
