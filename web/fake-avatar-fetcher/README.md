# 🖼 سرویس آواتار تصادفی (Random Avatar Fetcher)

> 📬 **Telegram:** [@Abolfazl_rwm](https://t.me/Abolfazl_rwm)

اسکریپت PHP کوچک از @Dev_Amiri که پروفایل تصادفی از randomuser.me می‌گیرد، تصویر را در پوشه‌ی `pic/` ذخیره می‌کند و خروجی JSON می‌دهد — مناسب پروفایل‌سازها و تست‌ها.

## ✨ امکانات

- دریافت پروفایل تصادفی از randomuser.me
- ذخیره‌ی تصویر در `pic/` (ساخت خودکار)
- خروجی JSON تمیز
- گزارش خطای curl

## 📋 پیش‌نیازها

- PHP ۷.۴+ با افزونه‌ی curl

## ⚙️ نصب و راه‌اندازی

### گام ۱: پیکربندی
1. دامین خود را در `$domain` بگذارید و اجازه‌ی نوشتن پوشه‌ی `pic/` را بدهید.

### گام ۲: اجرا
```bash
php -S localhost:8000
```
