## ✨ Features

- 📏 **Five categories** — length (mm → nautical mile), mass (mg → ton), temperature (C/F/K with real offset formulas), data (byte → TB, binary 1024) and speed (m/s → Mach)
- ⚡ **Live conversion** — results update on every keystroke, with smart formatting (precision 10, exponential for extremes)
- ⇄ **Swap button** — flip from/to units in one click
- 🇮🇷 **Bilingual units** — every unit shows its Persian and symbol name
- 📚 **Reference strip** — the key factors (1 lb = 453.59237 g, F = C×9/5+32, …) always visible
- 🔒 Zero dependencies, works offline from `file://`

## 🚀 Demo / اجرا

```bash
cd src/unit-converter-web
python3 -m http.server 8080   # or just open index.html
```
