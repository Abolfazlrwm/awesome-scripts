# 🧪 زمین تمرین جاوااسکریپت (JS Practice Playground)

> 📬 **Telegram:** [@Abolfazl_rwm](https://t.me/Abolfazl_rwm)

تمرین‌های کلاسیک مبتدیِ جاوااسکریپت — سازنده‌ی مثلث و هرم ستاره‌ای و بازی حدس عدد — به‌صورت یک صفحه‌ی تعاملی قابل اجرا در مرورگر. فایل اصلی `Game.js` **دست‌نخورده** کنار صفحه مانده و صفحه‌ی `index.html` همان منطق را با خروجی DOM باز-executable می‌کند.

## ✨ امکانات

- ▲ مثلث ستاره‌ای: `n` سطر با `"* ".repeat(i)`
- ⭐ هرم ستاره‌ای: سطرهای وسط‌چین با padding فاصله
- 🎲 حدس عدد: عدد مخفی ۰–۹، راهنمای کمتر/بیشتر و شمارش تلاش‌ها
- 🖥 خروجی به‌جای console، داخل صفحه با `<pre>` رندر می‌شود
- 📱 واکنش‌گرا، بدون وابستگی، تک‌فایل HTML
- 🧾 دکمه‌ی لینک به سورس اصلی `Game.js` برای مقایسه‌ی کد

## 🚀 اجرا

هیچ نصبی لازم نیست:

- **آنلاین:** [دموی زنده](https://abolfazlrwm.github.io/awesome-scripts/web/js-practice-playground/)
- **لوکال:** فایل `index.html` را در مرورگر باز کنید.

سورس تمرین‌ها در `Game.js` است — می‌توانید همان را در کنسول مرورگر هم اجرا کنید (خروجی `prompt`/`console`).

## 🎓 مناسب برای

شروع یادگیری JS: حلقه‌ها (`for`)، `repeat`، `Math.random`، حلقه‌ی `while`، شرط‌ها و ورودی/خروجی — با مثال‌های قابل لمس.
