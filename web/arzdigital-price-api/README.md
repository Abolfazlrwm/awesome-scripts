# 📊 API قیمت ارز دیجیتال (ArzDigital Price API)

> 📬 **Telegram:** [@Abolfazl_rwm](https://t.me/Abolfazl_rwm)

API قیمت ارزهای دیجیتال بر پایه‌ی سرویس ArzDigital با کش فایل: قیمت‌ها ۵ دقیقه و فهرست نام‌ها یک روز کش می‌شوند؛ خروجی JSON آماده برای ربات‌ها و سایت‌ها.

## ✨ امکانات

- دریافت قیمت از ArzDigital
- کش فایل ۵ دقیقه‌ای قیمت‌ها
- کش روزانه‌ی فهرست نام‌ها
- خروجی JSON استاندارد
- مناسب ربات‌های نرخ

## 📋 پیش‌نیازها

- PHP ۷.۴+ با curl

## ⚙️ نصب و راه‌اندازی

### گام ۱: پیکربندی
1. مستقیم اجرا کنید؛ مسیر کش‌ها در ثابت‌های `CACHE_FILE` و `NAMES_CACHE_FILE` قابل تغییر است.

### گام ۲: اجرا
```bash
php -S localhost:8000
```
