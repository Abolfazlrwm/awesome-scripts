# 🗂 دایرکتوری وب‌سرویس‌ها (Web Services Directory)

> 📬 **Telegram:** [@Abolfazl_rwm](https://t.me/Abolfazl_rwm)

سایت دایرکتوری وب‌سرویس‌های کاربردی با پنل مدیریت کامل: افزودن/ویرایش سرویس با جزئیات متن/جدول/کد/دکمه، آمار بازدید، محبوب‌ترین سرویس‌ها و اسکیمای MySQL آماده.

## ✨ امکانات

- پنل مدیریت (`admin.php`) با افزودن/ویرایش سرویس
- جزئیات چهارگانه: متن، جدول، کد، دکمه
- شمارش بازدید و محبوب‌ترین‌ها
- اسکیمای MySQL داخلی
- رابط فارسی تمیز

## 📋 پیش‌نیازها

- PHP ۷.۴+ و MySQL
