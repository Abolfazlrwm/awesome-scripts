# 🎡 Wheel of Actions | چرخ اولویت‌بندی تسک‌های روزانه

یک ابزار وب کاملاً سمت کاربر (بدون نیاز به سرور یا بک‌اند) برای کمک به تصمیم‌گیری روزانه — کارهایت را با امتیاز وزن‌دهی کن، بچرخان و بگذار چرخ به‌صورت آماری در طول زمان دقیقاً به همون نسبتی که خواستی، وقتت را بین کارها تقسیم کند.

## ✨ امکانات

- 🎯 تعریف کارهای روزانه با امتیاز اختصاصی (هر چه امتیاز بیشتر، احتمال انتخاب بیشتر)
- 🔥 ثبت Daily Streak (رکورد روزهای متوالی) با حالت «دستاورد»
- 🎚 تعیین هدف تعداد چرخش روزانه و فاصله‌ی زمانی بین چرخش‌ها
- 🤖 ساخت خودکار پرامپت برای هوش مصنوعی (کمک به تعیین اولویت‌ها بر اساس فوریت/اهمیت/لذت/تکرار)
- 💾 ایمپورت و اکسپورت کامل داده‌ها (فایل JSON)
- 🎨 چند تم رنگی و پس‌زمینه‌ی سفارشی قابل آپلود
- 🌍 چندزبانه: فارسی، انگلیسی، چینی، ترکی، عربی
- 📅 تقویم ماهانه با نمایش تاریخچه‌ی چرخش‌ها
- 📱 کاملاً ریسپانسیو — روی موبایل، تبلت و دسکتاپ به‌خوبی نمایش داده می‌شود
- 📤 اشتراک‌گذاری دستاورد به‌صورت کارت تصویری
- 🔒 تمام داده‌ها فقط در همان مرورگر (localStorage) ذخیره می‌شوند — هیچ داده‌ای به سروری ارسال نمی‌شود

## ⚙️ نصب و راه‌اندازی

هیچ نصب یا سروری لازم نیست! دو روش برای استفاده داری:

### روش ۱: اجرای مستقیم (ساده‌ترین حالت)
فایل `index.html` را دوبار کلیک کن — مستقیم در مرورگرت باز می‌شود و آماده‌ی استفاده است.

### روش ۲: میزبانی رایگان با GitHub Pages
1. وارد تنظیمات همین ریپازیتوری شو: **Settings → Pages**
2. از بخش Source، شاخه (branch) و پوشه‌ی `wheel-of-actions` را انتخاب کن
3. بعد از چند ثانیه یک لینک عمومی برایت ساخته می‌شود که می‌توانی از هر دستگاهی بازش کنی
