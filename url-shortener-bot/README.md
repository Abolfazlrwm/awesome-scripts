# 🔗 ربات کوتاه‌کننده‌ی لینک (URL Shortener Bot)

هر لینکی برای ربات بفرستی، برات یه نسخه‌ی کوتاه می‌سازه و آمار تعداد کلیک روش رو هم نگه می‌داره. ربات یک سرور HTTP کوچک همراه خودش اجرا می‌کند که مسئول ریدایرکت لینک‌های کوتاه‌شده به آدرس اصلی است.

## ✨ امکانات

- ✂️ کوتاه کردن هر لینکی با فقط فرستادنش برای ربات
- 📊 شمارش دقیق تعداد کلیک هر لینک
- 📋 مشاهده‌ی لیست همه‌ی لینک‌های ساخته‌شده‌ی خودت
- 🌐 سرور ریدایرکت داخلی (Node.js خالص، بدون فریم‌ورک اضافه)
- 💾 ذخیره‌سازی با فایل JSON — بدون نیاز به دیتابیس خارجی

## 📋 پیش‌نیازها

- Node.js نسخه‌ی ۱۸ یا بالاتر
- یک سرور یا هاست که بتونه پورت مشخصی (پیش‌فرض `3000`) رو بیرون از شبکه در دسترس بذاره، یا یک دامنه که با Reverse Proxy (مثل Nginx) به این پورت وصل بشه

## ⚙️ نصب و راه‌اندازی

### گام ۱: نصب وابستگی‌ها
```bash
npm install
```

### گام ۲: تنظیمات اولیه
فایل `bot.js` را باز کن و مقادیر زیر را جایگزین کن:

| متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | توکن ربات از [@BotFather](https://t.me/BotFather) |
| `HTTP_PORT` | پورتی که سرور ریدایرکت روش اجرا می‌شه (پیش‌فرض ۳۰۰۰) |
| `PUBLIC_BASE_URL` | آدرس عمومی سرورت — روی سرور واقعی حتماً باید با دامنه‌ی خودت جایگزین بشه (مثلاً `https://short.yourdomain.com`) |

### گام ۳: اجرا
```bash
npm start
```

پس از اجرا، هم ربات تلگرام و هم سرور ریدایرکت (روی پورت تنظیم‌شده) هم‌زمان بالا می‌آیند.

### گام ۴ (روی سرور واقعی): اتصال دامنه
اگر روی یک VPS اجرا می‌کنی، برای اینکه لینک‌های کوتاه‌شده زیبا و حرفه‌ای باشند (مثل `https://short.ir/abc12`)، پیشنهاد می‌شود از Nginx به‌عنوان Reverse Proxy به پورت داخلی ربات استفاده کنی و `PUBLIC_BASE_URL` را با همان دامنه به‌روزرسانی کنی.
