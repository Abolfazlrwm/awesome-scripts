# 💰 ربات نرخ لحظه‌ای رمزارز (Price Ticker Bot)

نمایش قیمت لحظه‌ای رمزارزهای محبوب (از CoinGecko، کاملاً رایگان و بدون نیاز به کلید API)، هشدار قیمت شخصی برای هر کاربر و ارسال خودکار آپدیت قیمت به گروه یا کانال در بازه‌های زمانی مشخص.

## ✨ امکانات

- 📊 نمایش نرخ لحظه‌ای رمزارزهای محبوب (BTC, ETH, USDT, BNB, XRP, DOGE, TON و ...) به همراه درصد تغییر ۲۴ ساعته
- 🔍 استعلام قیمت یک کوین خاص با `/coin`
- 🔔 هشدار قیمت شخصی: تنظیم کن کِی قیمت از یه حد خاص بالاتر/پایین‌تر رفت بهت خبر بدم
- 📢 اشتراک آپدیت خودکار قیمت برای هر گروه/کانال (هر چند ساعت یک‌بار)
- ➕ افزودن/حذف کوین جدید به لیست ردیابی توسط ادمین
- 🆓 کاملاً رایگان — از API عمومی CoinGecko استفاده می‌کند، نیازی به ثبت‌نام یا کلید API نیست
- 💾 ذخیره‌سازی با فایل JSON — بدون نیاز به دیتابیس خارجی

## 📋 پیش‌نیازها

- Node.js نسخه‌ی ۱۸ یا بالاتر (برای پشتیبانی از `fetch` داخلی)

## ⚙️ نصب و راه‌اندازی

### گام ۱: نصب وابستگی‌ها
```bash
npm install
```

### گام ۲: تنظیمات اولیه
فایل `bot.js` را باز کن و مقادیر زیر را جایگزین کن:

| متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | توکن ربات از [@BotFather](https://t.me/BotFather) |
| `ADMIN_IDS` | لیست آیدی عددی مدیرانی که اجازه‌ی افزودن/حذف کوین دارند |
| `CHECK_INTERVAL_MINUTES` | هر چند دقیقه هشدارهای قیمت بررسی شوند (پیش‌فرض ۵) |
| `SCHEDULED_UPDATE_HOURS` | هر چند ساعت آپدیت خودکار ارسال شود (پیش‌فرض ۶) |

### گام ۳: اجرا
```bash
npm start
```

## 📖 دستورات

| دستور | توضیح |
|---|---|
| `/price` | نمایش قیمت همه‌ی کوین‌های ردیابی‌شده |
| `/coin btc` | نمایش قیمت یک کوین خاص |
| `/coinlist` | لیست کوین‌های قابل استعلام |
| `/alert btc above 70000` | هشدار وقتی قیمت BTC از ۷۰,۰۰۰ دلار بالاتر رفت |
| `/myalerts` | لیست هشدارهای فعال من |
| `/subscribe` | مشترک آپدیت خودکار در این چت شو |
| `/addcoin [شناسه‌ی CoinGecko] [نماد]` | (فقط ادمین) افزودن کوین جدید |

> 💡 برای پیدا کردن «شناسه‌ی CoinGecko» هر کوین، اسم کامل کوین (لاتین، با خط تیره) را در [coingecko.com](https://www.coingecko.com) جست‌وجو کن؛ همان چیزی که در آدرس صفحه‌اش می‌آید شناسه‌ی آن است — مثلاً برای Solana، شناسه `solana` است.
