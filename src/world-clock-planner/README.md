# 🌍 World Clock Planner

ابزار وبی برای هماهنگ کردن جلسات بین‌المللی — چند شهر رو اضافه کن، نوار زمان مشترک رو بکش و ببین یک لحظه‌ی خاص معادل چه ساعتی توی هر منطقه‌ی زمانیه؛ همراه با نوار بصری روز/شب و بازه‌ی ساعات کاری (۹ تا ۱۸) برای هر شهر.

## ✨ امکانات

- ➕ افزودن هر تعداد شهر/منطقه‌ی زمانی (لیست کامل مناطق زمانی استاندارد IANA)
- 🕐 نوار زمان مشترک قابل‌کشیدن (drag) که همه‌ی شهرها رو هم‌زمان به‌روزرسانی می‌کنه
- 🌗 گرادیانت بصری روز/شب روی نوار هر شهر برای درک سریع «الان اونجا صبحه یا شب؟»
- 🟢 نوار سبز بازه‌ی ساعات کاری معمول (۹ تا ۱۸) روی هر تایم‌لاین
- 🔄 دکمه‌ی «برگشت به اکنون» برای ریست سریع به لحظه‌ی فعلی
- 💻 کاملاً سمت مرورگر، با API استاندارد `Intl`— بدون هیچ کتابخانه یا سرویس خارجی

## ⚙️ نصب و راه‌اندازی
