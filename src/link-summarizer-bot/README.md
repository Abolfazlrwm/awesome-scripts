# 📄 ربات خلاصه‌ساز لینک و متن (Link/Text Summarizer Bot)

یک لینک بفرست، محتوای صفحه استخراج و خلاصه می‌شود؛ یک متن بلند بفرست، همان‌جا خلاصه‌اش را می‌گیری. از همون اول — بدون هیچ تنظیم یا کلید API‌ای — با یک الگوریتم خلاصه‌سازی استخراجی سبک کار می‌کند؛ و در صورت تمایل، با وصل‌کردن یک کلید مدل زبانی (سازگار با OpenAI API)، خودکار ارتقا پیدا می‌کند به خلاصه‌های روان‌تر و طبیعی‌تر.

## ✨ امکانات

- 🔗 پشتیبانی از لینک — استخراج خودکار متن اصلی صفحه (حذف منو، فوتر، تبلیغات)
- 📝 پشتیبانی از متن مستقیم — هر متن بلندی که بفرستی
- 🧮 خلاصه‌سازی استخراجی رایگان و آفلاین (بدون نیاز به هیچ API) به‌عنوان پیش‌فرض
- 🧠 ارتقای اختیاری به خلاصه‌سازی مبتنی بر مدل زبانی، فقط با تنظیم یک کلید API
- 🌍 چندزبانه — الگوریتم پیش‌فرض روی فارسی و انگلیسی هر دو کار می‌کند
- 📏 سه حالت طول خلاصه: کوتاه / متوسط / بلند (`/length`)

## 📋 پیش‌نیازها

- Python نسخه‌ی ۳.۹ یا بالاتر

## ⚙️ نصب و راه‌اندازی

### گام ۱: نصب وابستگی‌ها
```bash
pip install -r requirements.txt
```

### گام ۲: تنظیم توکن
فایل `bot.py` را باز کن و `BOT_TOKEN` را با توکن گرفته‌شده از [@BotFather](https://t.me/BotFather) جایگزین کن.

### گام ۳ (اختیاری): فعال‌سازی خلاصه‌سازی با مدل زبانی
اگر می‌خوای خلاصه‌ها خیلی روان‌تر و باکیفیت‌تر باشن، در همون فایل `bot.py`:

| متغیر | توضیح |
|---|---|
| `LLM_API_KEY` | کلید API خودت (OpenAI یا هر سرویس سازگار مثل OpenRouter) |
| `LLM_BASE_URL` | آدرس پایه‌ی API — پیش‌فرض OpenAI؛ برای OpenRouter مثلاً `https://openrouter.ai/api/v1` |
| `LLM_MODEL` | نام مدل مورد نظر |

اگر این کلید خالی بمونه، ربات همچنان کار می‌کنه — فقط با الگوریتم استخراجی داخلی به‌جای مدل زبانی.

### گام ۴: اجرا
```bash
python bot.py
```

## 📖 دستورات

| دستور | توضیح |
|---|---|
| `/start` | راهنما |
| `/length short` | خلاصه‌ی کوتاه (۲ جمله) |
| `/length medium` | خلاصه‌ی متوسط (پیش‌فرض، ۴ جمله) |
| `/length long` | خلاصه‌ی بلند (۷ جمله) |

فقط کافیه یک لینک یا متن بلند بفرستی — نیازی به دستور خاصی نیست.
