# 📁 ربات ذخیره فایل و لینک‌ساز (File Store Bot)

فایل رو به ربات بفرست، یه لینک اختصاصی بگیر — هرکی روی اون لینک بزنه همون فایل رو مستقیم از ربات دریافت می‌کنه. امکان ساخت لینک برای چند فایل هم‌زمان (Batch) و جوین اجباری قبل از دریافت فایل رو هم داره.

## ✨ امکانات

- 📤 آپلود فایل (عکس، ویدیو، فایل، صوت) و ساخت خودکار لینک اختصاصی دانلود
- 📦 حالت دسته‌ای (Batch): چند فایل رو زیر یک لینک واحد قرار بده
- 🔒 جوین اجباری قابل تنظیم قبل از دریافت فایل
- ⏱ حذف خودکار فایل ارسالی بعد از چند ثانیه (اختیاری — مناسب فایل‌های محرمانه)
- 👥 محدود کردن آپلود فقط به لیست مشخصی از ادمین‌ها
- 📊 آمار کلی: تعداد فایل‌های ذخیره‌شده و تعداد دانلودها
- 💾 ذخیره‌سازی با فایل JSON — بدون نیاز به دیتابیس خارجی

## 📋 پیش‌نیازها

- Node.js نسخه‌ی ۱۸ یا بالاتر

## ⚙️ نصب و راه‌اندازی

### گام ۱: نصب وابستگی‌ها
```bash
npm install
```

### گام ۲: تنظیمات اولیه
فایل `bot.js` را باز کن و مقادیر زیر را جایگزین کن:

| متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | توکن ربات از [@BotFather](https://t.me/BotFather) |
| `ADMIN_IDS` | لیست آیدی عددی افرادی که اجازه‌ی آپلود فایل دارند، مثل `[123456789]` |
| `FORCE_JOIN_CHANNEL` | یوزرنیم کانال جوین اجباری (اختیاری)، مثل `"@mychannel"` — خالی بگذار برای غیرفعال کردن |
| `AUTO_DELETE_SECONDS` | حذف خودکار فایل بعد از چند ثانیه (۰ = غیرفعال) |

### گام ۳: اجرا
```bash
npm start
```

## 📖 نحوه‌ی استفاده

### برای ادمین (آپلود تکی)
یک فایل مستقیم برای ربات در پیوی بفرست — بلافاصله لینک اختصاصی برمی‌گردد.

### برای ادمین (آپلود چند فایل زیر یک لینک)
```
/startbatch
[فایل ۱ را بفرست]
[فایل ۲ را بفرست]
...
/endbatch
```

### برای کاربر نهایی
فقط کافیست روی لینکی که از ادمین دریافت کرده باز کند.
