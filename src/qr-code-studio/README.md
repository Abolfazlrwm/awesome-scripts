# 🔳 QR Code Studio

ابزار وبی برای ساخت بارکد QR سفارشی — با رنگ دلخواه، گرادینت، پس‌زمینه، سطح تصحیح خطا و لوگوی مرکزی — و خروجی گرفتن با کیفیت بالا در قالب PNG یا SVG. کاملاً سمت مرورگر اجرا می‌شه؛ هیچ داده‌ای به هیچ سروری فرستاده نمی‌شه.

## ✨ امکانات

- 🎨 رنگ ثابت یا گرادینت دو رنگه برای ماژول‌های QR
- 🖼 افزودن لوگوی دلخواه در مرکز کد (با سطح تصحیح خطای بالا برای اسکن مطمئن)
- 🎛 کنترل سطح تصحیح خطا (L/M/Q/H)، سایز خروجی (تا 2048×2048) و حاشیه (Quiet Zone)
- 🌈 چند پیش‌فرض رنگی آماده برای شروع سریع
- ⬇️ خروجی PNG (پیکسلی، برای چاپ و استفاده مستقیم) و SVG (برداری، مقیاس‌پذیر بدون افت کیفیت)
- 🔒 کاملاً آفلاین‌پسند بعد از بارگذاری اولیه — بدون ارسال متن یا لینک به هیچ سروری

## ⚙️ نصب و راه‌اندازی

هیچ نصب یا سروری لازم نیست.

### روش ۱: اجرای مستقیم
فایل `index.html` را باز کن.

### روش ۲: میزبانی با GitHub Pages
از تنظیمات ریپازیتوری، مسیر `src/qr-code-studio` را به‌عنوان منبع Pages معرفی کن.

## 🧩 فناوری استفاده‌شده

رندر بارکد با کتابخانه‌ی سبک و پرکاربرد [`qrcode`](https://github.com/soldair/node-qrcode) انجام می‌شود؛ این کتابخانه به‌صورت محلی در فایل `vendor-qrcode.js` باندل شده (نه از طریق CDN) تا ابزار کاملاً آفلاین کار کند و به در دسترس بودن هیچ سرویس بیرونی وابسته نباشد. رنگ‌آمیزی گرادینت هم با ترکیب‌بندی (`compositing`) روی Canvas سمت کلاینت اضافه شده است.
