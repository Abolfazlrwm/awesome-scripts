# 📡 ربات مانیتور آپ‌تایم سایت/سرور (Uptime Monitor Bot)

سایت‌ها یا سرورهایی که بهش معرفی می‌کنی رو هر دقیقه چک می‌کنه؛ اگه یکی‌شون قطع بشه یا برگرده، فوری توی تلگرام بهت خبر می‌ده. یک صفحه‌ی وضعیت HTML هم خودکار می‌سازه که می‌تونی روی هر وب‌سروری میزبانی کنی.

![C#](https://img.shields.io/badge/C%23-.NET%208-512BD4.svg)
![HTML/CSS](https://img.shields.io/badge/status%20page-HTML%2FCSS-orange.svg)
![License](https://img.shields.io/badge/license-MIT-green)

## ✨ امکانات

- ⏱ بررسی دوره‌ای سایت‌ها (پیش‌فرض هر ۶۰ ثانیه)
- 🔴🟢 اطلاع‌رسانی فوری آنلاین/آفلاین شدن هر سایت
- 📊 دستور `/status` برای دیدن وضعیت لحظه‌ای همه‌ی سایت‌ها از داخل تلگرام
- ➕ افزودن/حذف سایت مستقیم از داخل ربات (`/addsite`, `/removesite`)
- 🌐 تولید خودکار صفحه‌ی وضعیت زیبا با HTML/CSS (`status.html`) — قابل میزبانی روی هر سروری
- 💾 ذخیره‌سازی با فایل JSON — بدون نیاز به دیتابیس خارجی
- 🧩 بدون هیچ وابستگی خارجی (NuGet) — فقط با ابزارهای built-in فریم‌ورک .NET نوشته شده

## 📋 پیش‌نیازها

- [.NET SDK نسخه‌ی ۸](https://dotnet.microsoft.com/download) یا بالاتر

## ⚙️ نصب و راه‌اندازی

### گام ۱: تنظیمات اولیه
فایل `Program.cs` را باز کن و این مقادیر را (ابتدای کلاس `Program`) جایگزین کن:

| ثابت | توضیح |
|---|---|
| `BOT_TOKEN` | توکن ربات از [@BotFather](https://t.me/BotFather) |
| `ADMIN_ID` | آیدی عددی خودت از [@userinfobot](https://t.me/userinfobot) |
| `CHECK_INTERVAL_SECONDS` | فاصله‌ی بررسی سایت‌ها (ثانیه) |

### گام ۲: اجرا
```bash
dotnet run
```

اولین بار که اجرا می‌کنی، `dotnet` به‌صورت خودکار وابستگی‌های لازم را از NuGet دریافت می‌کند (فقط ابزارهای استاندارد فریم‌ورک، بدون پکیج اضافه).

### گام ۳: افزودن اولین سایت
از داخل ربات در تلگرام:
```
/addsite گیتهاب https://github.com
```

## 🌐 استفاده از صفحه‌ی وضعیت

بعد از هر بار بررسی، فایل `status.html` در همان پوشه به‌روزرسانی می‌شود. کافی است این فایل را با هر وب‌سروری (Nginx, Apache, یا حتی `python3 -m http.server`) سرو کنی تا یک صفحه‌ی وضعیت زنده داشته باشی.
