# 📥 ربات دانلود از اینستاگرام (Instagram Downloader)

ربات دانلود پست، ریلز و استوری اینستاگرام با کیفیت اصلی، همراه با سیستم محدودیت روزانه، عضویت VIP نامحدود و دعوت دوستان.

![Python](https://img.shields.io/badge/python-3.8+-blue.svg)
![pyTelegramBotAPI](https://img.shields.io/badge/pyTelegramBotAPI-latest-2CA5E0.svg)
![License](https://img.shields.io/badge/license-MIT-green)

## ✨ امکانات

- ⬇️ دانلود پست، ریلز و استوری اینستاگرام با کیفیت اصلی
- 🚀 سرعت دانلود بالا
- ⭐ سیستم کاربر VIP با دانلود نامحدود (قابل فعال‌سازی توسط ادمین، موقت یا دائمی)
- 📊 محدودیت روزانه‌ی رایگان برای کاربران عادی (قابل تنظیم)، با ریست خودکار شبانه
- 🎁 سیستم دعوت دوستان: هر دعوت موفق = دانلود اضافه برای هر دو طرف
- 🔒 عضویت اجباری در کانال(های) دلخواه، با بررسی هوشمند وضعیت عضویت
- 🎛 پنل مدیریت کامل: آمار کلی، مدیریت VIP، ارسال همگانی، مدیریت کانال‌های اجباری، ریست دانلود کاربر، پیام مستقیم به کاربر، پشتیبان‌گیری از دیتابیس
- 🆘 سیستم پشتیبانی دسته‌بندی‌شده (اسپانسر، تبلیغات، باگ، سایر موارد)
- 📈 آمار کاربری کامل برای هر کاربر (تعداد دانلود، دعوت‌ها و ...)

## 📋 پیش‌نیازها

- Python نسخه‌ی ۳.۸ یا بالاتر
- کتابخانه‌های `pyTelegramBotAPI` و `requests`
- دسترسی به یک API دانلود اینستاگرام (توکن مربوطه)

## ⚙️ نصب و راه‌اندازی

### گام ۱: نصب وابستگی‌ها
```bash
pip install -r requirements.txt

### گام ۲: تنظیمات اولیه
فایل `bot.py` را باز کن و مقادیر زیر را (نزدیک ابتدای فایل) جایگزین کن:

| متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | توکن ربات از [@BotFather](https://t.me/BotFather) |
| `ADMIN_ID` | آیدی عددی ادمین از [@userinfobot](https://t.me/userinfobot) |
| `FAST_CREAT_TOKEN` | توکن API دانلود اینستاگرام |
| `SUPPORT_USERNAME` | یوزرنیم پشتیبانی ربات |
| `CHANNEL_USERNAME` / `CHANNEL_LINK` | یوزرنیم و لینک کانال اطلاع‌رسانی |

### گام ۳: اجرا
```bash
python bot.py

پایگاه‌داده (`instagram_bot.db`) به‌صورت خودکار ساخته می‌شود.

### گام ۴: تنظیم کانال جوین اجباری (اختیاری)
از پنل مدیریت («👑 پنل مدیریت» → «➕ افزودن کانال») کانال دلخواه را اضافه کن.
