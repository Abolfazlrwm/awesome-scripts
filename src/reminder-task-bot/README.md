# ⏰ ربات یادآوری و تسک روزانه (Reminder & Task Bot)

یک ربات تلگرامی برای مدیریت کارهای روزمره و یادآوری‌ها — از یادآوری‌های یک‌باره‌ی «۳۰ دقیقه‌ی دیگه» تا یادآوری‌های تکرارشونده‌ی روزانه، به‌همراه لیست تسک با دکمه‌های شیشه‌ای. تمام یادآوری‌های فعال بعد از ری‌استارت ربات هم دوباره خودکار زمان‌بندی می‌شوند — چیزی گم نمی‌شود.

## ✨ امکانات

- 📋 لیست تسک با دکمه‌ی «انجام‌شد» و «حذف»
- ⏱ یادآوری یک‌باره با فاصله‌ی دقیقه‌ای (`/remind 30 متن`)
- 🕐 یادآوری یک‌باره در ساعت مشخص (`/remind_at 18:30 متن`)
- 🔁 یادآوری تکرارشونده‌ی روزانه (`/remind_daily 08:00 متن`)
- 😴 دکمه‌ی «۱۰ دقیقه دیگه یادم بنداز» (Snooze) زیر هر پیام یادآوری
- 💾 ذخیره‌سازی در SQLite — با ری‌استارت ربات، یادآوری‌های فعال از دست نمی‌روند

## 📋 پیش‌نیازها

- Python نسخه‌ی ۳.۹ یا بالاتر

## ⚙️ نصب و راه‌اندازی

### گام ۱: نصب وابستگی‌ها
```bash
pip install -r requirements.txt
```

### گام ۲: تنظیم توکن
فایل `bot.py` را باز کن و مقدار `BOT_TOKEN` را با توکن گرفته‌شده از [@BotFather](https://t.me/BotFather) جایگزین کن.

### گام ۳: اجرا
```bash
python bot.py
```

## 📖 دستورات

| دستور | توضیح |
|---|---|
| `/task <متن>` | افزودن یک کار به لیست |
| `/tasks` | نمایش لیست کارها |
| `/remind <دقیقه> <متن>` | یادآوری بعد از N دقیقه |
| `/remind_at HH:MM <متن>` | یادآوری امروز (یا فردا) در ساعت مشخص |
| `/remind_daily HH:MM <متن>` | یادآوری تکرارشونده‌ی هر روز |
| `/myreminders` | لیست یادآوری‌های فعال + لغو |
