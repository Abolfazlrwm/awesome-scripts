# 🎛 اتاق فرمان | Control Room Dashboard

یک داشبورد زنده و شبیه‌سازی‌شده که وضعیت مجموعه‌ای از ربات‌ها و ابزارهای این ریپازیتوری را به‌صورت بصری و لحظه‌ای نمایش می‌دهد — کاملاً سمت کاربر، بدون نیاز به سرور یا اتصال واقعی به هیچ ربات یا API.

![HTML5](https://img.shields.io/badge/HTML5-E34F26.svg)
![No Backend](https://img.shields.io/badge/backend-none%20needed-success)
![License](https://img.shields.io/badge/license-MIT-green)

## ✨ امکانات

- 🔢 شمارنده‌ی انیمیشنی «کاربران فعال شبکه» با افکت easing
- 🖥 ترمینال لاگ زنده با خط‌های رنگی (OK / INFO / WARN) که به‌صورت خودکار اضافه و اسکرول می‌شوند
- 🤖 لیست وضعیت ربات‌ها با پینگ لحظه‌ای و نشانگر آنلاین/مشغول
- 📈 نمودار نرخ لحظه‌ای (mini price ticker) با رسم روی Canvas و گرادیانت رنگی بر اساس روند صعودی/نزولی
- 🌗 طراحی تیره و راست‌به‌چپ (RTL) با فونت Vazirmatn و JetBrains Mono
- 📱 ریسپانسیو برای موبایل و دسکتاپ

> ⚠️ همه‌ی اعداد و لاگ‌های این صفحه **شبیه‌سازی‌شده** هستند و به هیچ ربات یا سرویس واقعی متصل نیستند؛ این پروژه صرفاً یک نمایش بصری (UI demo) است.

## ⚙️ نصب و راه‌اندازی

هیچ نصب یا سروری لازم نیست.

### روش ۱: اجرای مستقیم
فایل `index.html` را دوبار کلیک کن — مستقیم در مرورگرت باز می‌شود.

### روش ۲: میزبانی رایگان با GitHub Pages
1. وارد تنظیمات ریپازیتوری شو: **Settings → Pages**
2. از بخش Source، شاخه (branch) و پوشه‌ی `control-room-dashboard` را انتخاب کن
3. بعد از چند ثانیه یک لینک عمومی برایت ساخته می‌شود
