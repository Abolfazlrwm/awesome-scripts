# معماری Emoji Forge AI

## انتخاب‌ها بر اساس قابلیت‌های تأییدشده (نه فرض)

- زبان: Python 3.12 (موجود در محیط) + Pillow + requests + FFmpeg.
  بدون OpenCV، بدون python-lottie، بدون API پولی.
- ربات: Polling با Bot API خام (بدون وابستگی سنگین) — چون وب‌هوک به
  دامنه/گواهی نیاز دارد و در این VM قابل‌اعتماد نیست.
- اجرا: این VM دائمی نیست؛ برای اجرای دائمی همان کد با فایل
  ‎systemd/emoji-forge-ai.service‎ به VPS منتقل می‌شود.
- داده: زیر ‎data/‎ همین پوشه (پایدار)، هرگز ‎/tmp‎.

## اجزا

| فایل | نقش |
|---|---|
| ‎config.py‎ | فقط متغیر محیطی؛ هیچ رمزی در کد نیست |
| ‎telegram_api.py‎ | Bot API: getMe/getUpdates/getCustomEmojiStickers/getStickerSet/getFile/download + uploadStickerFile/createNewStickerSet/addStickerToSet |
| ‎bot.py‎ | منوی فارسی، دستورها، جریان ایموجی/استیکر/لینک/فایل، پیش‌نمایش و تأیید، صف پردازش کامل |
| ‎pack.py‎ | استخراج custom_emoji_id از Entity، پارس لینک t.me/addemoji و addstickers، ساخت Manifest از getStickerSet |
| ‎storage.py‎ | پوشه پروژه، نام‌گذاری منظم، manifest/brand/report، jobs.json برای بازیابی |
| ‎formats.py‎ | تشخیص Magic، ابعاد TGS، محدودیت‌های استیکر/ایموجی |
| ‎cleaning.py‎ | حالت A: پرکردن با میانگین حاشیه بیرونی؛ حالت B: + تغییر ملایم رنگ خارج ناحیه، با حفظ پیکسل شبه‌پوست (قاعده رنگی، نه تشخیص چهره) |
| ‎brand.py‎ | پروفایل برند، اعتبارسنجی HEX، جایگاه/اندازه لوگو، وفاداری و شدت بازطراحی |
| ‎image_engine.py‎ | ثابت: حفظ شفافیت، خروجی ۱۰۰×۱۰۰ برای ایموجی یا ۵۱۲ برای استیکر، لوگوی دوبعدی + درخشش، نام برند |
| ‎animation_engine.py‎ | TGS: پنهان‌کردن لایه لوگو/متن، بازرنگی Fill، بدون تغییر fr/ip/op؛ WEBM: فریم‌به‌فریم با همان پارامترها + VP9 بدون صدا، تا ۲۵۶KB |
| ‎pipeline.py‎ | اعتبارسنجی → پاک‌سازی → برند → کنترل حد → پیش‌نمایش/کامل؛ کش افزایشی: اگر تنظیمات عوض نشده، خروجی قبلی دوباره ساخته نمی‌شود |
| ‎queue.py‎ | یک Worker؛ کار طولانی ربات را قفل نمی‌کند؛ پس از ری‌استارت، کارهای running به interrupted تبدیل می‌شوند |
| ‎export.py‎ | ZIP مرتب‌شده، گزارش JSON/Markdown برای هر فایل، راهنمای انتشار رسمی |
| ‎security.py‎ | گیت مدیر، حد حجم/نوع، Magic به‌جای پسوند، خنثی‌سازی Path Traversal، سانسور توکن در لاگ، پاک‌سازی فایل قدیمی |

## جریان داده

پیام → custom_emoji_id / set_name / لینک / فایل → دانلود و Manifest →
پروفایل برند + ناحیه پاک‌سازی → پیش‌نمایش ۳ نمونه (اول/وسط/آخر) →
تأیید کاربر → صف پردازش کامل → ZIP + گزارش → (اختیاری) ساخت ست جدید
توسط ربات یا انتشار دستی با ZIP.

## امنیت و تجاری

- فایل ورودی هرگز اجرا نمی‌شود؛ فقط با Pillow/FFmpeg خوانده می‌شود.
- حد هم‌زمانی: ‎EMOJI_FORGE_MAX_CONCURRENT‎ (پیش‌فرض ۲، سقف کد ۴).
- بدون درگاه پرداخت در نسخه اول؛ ساختار پروژه/سفارش/مشتری جداست تا
  بعداً ثبت سفارش + قیمت‌گذاری + پرداخت اضافه شود.
- فقط فایل‌هایی پردازش شوند که حق تغییرشان وجود دارد — این مسئولیت
  کاربر/مشتری است و ربات آن را بررسی خودکار نمی‌کند (محدودیت صادقانه).
