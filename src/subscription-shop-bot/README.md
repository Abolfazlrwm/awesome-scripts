# 💳 ربات فروش اشتراک و کانفیگ (Subscription Shop Bot)

ربات فروش خودکار اشتراک/کانفیگ از یک مخزن داخلی، با سیستم نمایندگی، گردونه‌ی شانس و کیف پول داخلی. مناسب برای فروش کانفیگ، اشتراک سرویس یا هر محصول دیجیتال تکرارشونده.

![pyTelegramBotAPI](https://img.shields.io/badge/pyTelegramBotAPI-latest-2CA5E0.svg)
![License](https://img.shields.io/badge/license-MIT-green)

## ✨ امکانات

- 📦 مخزن کانفیگ با افزودن دستی (هر خط = یک کانفیگ)
- 🛒 خرید اشتراک با پرداخت از کیف پول یا کارت‌به‌کارت (تأیید توسط ادمین)
- 🔑 اکانت تست رایگان روزانه
- 🎲 گردونه‌ی شانس (Lucky Wheel) با جایزه‌ی نقدی
- 👑 سیستم نمایندگی با تخفیف ۱۰٪ دائمی برای نمایندگان
- 👥 زیرمجموعه‌گیری و پورسانت معرفی (Referral)
- 🏦 کیف پول داخلی و شارژ با رسید بانکی
- 🔗 قابلیت روشن/خاموش کردن جوین اجباری و تغییر کانال از پنل مدیریت
- 🎛 پنل مدیریت کامل: مخزن کانفیگ، آمار، مدیریت کاربران، ارسال همگانی، تنظیمات عمومی
- ✏️ سرویس‌های من: تمدید اشتراک، دریافت مجدد لینک، تغییر لینک ساب، حذف کانفیگ

## 📋 پیش‌نیازها

- Python نسخه‌ی ۳.۸ یا بالاتر
- کتابخانه‌ی `pyTelegramBotAPI`

## ⚙️ نصب و راه‌اندازی

### گام ۱: نصب وابستگی‌ها
```bash
pip install -r requirements.txt

### گام ۲: تنظیمات اولیه
فایل `bot.py` را باز کن و مقادیر زیر را (نزدیک ابتدای فایل) تنظیم کن:

| متغیر | توضیح |
|---|---|
| `API_TOKEN` | توکن ربات از [@BotFather](https://t.me/BotFather) |
| `OWNER_ID` | آیدی عددی مالک ربات از [@userinfobot](https://t.me/userinfobot) |
| `CHANNEL_ID` | آیدی کانال جوین اجباری (مثال: `@mychannel`) |
| `CARD_NUMBER` | شماره کارت برای دریافت وجه |
| `CARD_NAME` | نام صاحب کارت |
| `REFERRAL_BONUS` | مقدار پاداش معرفی (پیش‌فرض ۵۰۰۰) |
| `LUCKY_BONUS` | مقدار جایزه‌ی گردونه‌ی شانس (پیش‌فرض ۵۰۰۰) |

### گام ۳: اجرا
```bash
python bot.py

پایگاه‌داده (`shop_bot.db`) به‌صورت خودکار ساخته می‌شود.

### گام ۴: افزودن محصول و کانفیگ
از داخل ربات، وارد «⚙️ تنظیمات عمومی» → «➕ افزودن محصول» شو (فرمت: `نام|قیمت|مدت به روز`)، سپس از «📦 مخزن کانفیگ» کانفیگ‌ها را (هر خط یکی) اضافه کن.
