## 📖 توضیحات

مجموعه‌ای از **۱۲ قالب صفحه‌ی فرود (Landing Page)** آماده و ریسپانسیو برای معرفی و دانلود اپلیکیشن موبایل. هر فایل یک صفحه‌ی مستقل و کامل (HTML + CSS + JS درون‌خطی) است — کافیست فایل موردنظر را باز کرده و متن، رنگ‌بندی و لینک‌های دانلود را با محتوای اپلیکیشن خودتان جایگزین کنید.

## ✨ ویژگی‌های مشترک

- کاملاً ریسپانسیو (موبایل، تبلت، دسکتاپ)
- بدون نیاز به هیچ فریم‌ورک یا build tool — فقط باز کردن در مرورگر
- بخش‌های استاندارد یک صفحه‌ی معرفی اپ: هیرو، ویژگی‌ها، اسکرین‌شات‌ها، دکمه‌های دانلود (App Store / Google Play)، فوتر
- قابل استفاده به‌عنوان نقطه‌ی شروع برای هر پروژه‌ی معرفی اپلیکیشن

## ⚙️ نحوه‌ی استفاده

1. یکی از فایل‌های `template-XX.html` را انتخاب و باز کنید.
2. متن‌ها، تصاویر و لینک‌های دکمه‌ی دانلود را با اطلاعات واقعی اپلیکیشن خود جایگزین کنید.
3. فایل را روی هر هاست استاتیک (GitHub Pages، Netlify، Vercel، یا هر هاست معمولی) قرار دهید.

## English

A collection of **12 ready-made, responsive landing pages** for introducing and promoting a mobile app. Each file is a fully self-contained page (inline HTML/CSS/JS) — open the one you like, swap in your app's copy, screenshots, and store links, and deploy anywhere as a static page (GitHub Pages, Netlify, Vercel, etc.). No build step or framework required.
