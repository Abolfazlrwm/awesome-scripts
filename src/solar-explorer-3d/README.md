# 🪐 کاوشگر سه‌بعدی منظومه شمسی | Solar Explorer 3D

یک شبیه‌سازی سه‌بعدی تعاملی از منظومه شمسی، کاملاً سمت کاربر و بدون نیاز به سرور یا بک‌اند — با Three.js. سرعت زمان را تغییر بده، روی هر سیاره کلیک کن، دوربین را دنبال‌کننده‌اش کن و اطلاعات علمی هرکدام را ببین.

## ✨ امکانات

- ☀️ شبیه‌سازی خورشید و همه سیارات منظومه شمسی به همراه چند قمر (از جمله ماه) و حلقه‌های زحل
- ⏱ کنترل سرعت گذر زمان (۱×, ۱۰×, ۱۰۰×, ۱۰۰۰×, ۱۰۰۰۰×) و دکمه توقف/ادامه
- 🖱 چرخش، زوم و جابه‌جایی آزاد دوربین (OrbitControls) + قابلیت دنبال‌کردن یک سیاره خاص
- 🔍 لیست و جستجوی سیارات در نوار کناری
- 📊 پنل اطلاعات هر سیاره: قطر، جرم، فاصله از خورشید (AU)، دوره تناوب مداری، دوره چرخش، دما، تعداد اقمار، گرانش و ترکیب سطحی
- 🏷 برچسب نام روی هر جرم آسمانی (CSS2DRenderer)
- 📱 طراحی ریسپانسیو برای موبایل و دسکتاپ

## ⚙️ نصب و راه‌اندازی

هیچ نصب یا سروری لازم نیست. کتابخانه Three.js از طریق CDN (unpkg) با import map بارگذاری می‌شود، پس فقط به یک اتصال اینترنت نیاز داری.

### روش ۱: اجرای مستقیم
فایل `index.html` را دوبار کلیک کن — مستقیم در مرورگرت باز می‌شود.

> نکته: به‌خاطر محدودیت‌های ماژول‌های ES در برخی مرورگرها، اگر صفحه سفید ماند، آن را از طریق یک سرور محلی ساده هم امتحان کن:
> `python -m http.server` و سپس باز کردن `http://localhost:8000`

### روش ۲: میزبانی رایگان با GitHub Pages
1. وارد تنظیمات ریپازیتوری شو: **Settings → Pages**
2. از بخش Source، شاخه (branch) و پوشه‌ی `solar-explorer-3d` را انتخاب کن
3. بعد از چند ثانیه یک لینک عمومی برایت ساخته می‌شود

## 🕹 کنترل‌های اضافی از کنسول مرورگر

```js
toggleOrbits(false)  // مخفی کردن خطوط مدار
toggleLabels(false)  // مخفی کردن برچسب‌های نام
```
