# 🌐 ربات آزادی‌نت (FreedomNet VPN Config Bot)

یک ربات تلگرامی برای توزیع کانفیگ‌های VPN (VLESS/Trojan) بین کاربران، همراه با پنل مدیریت کامل، تولید QR کد برای اتصال سریع، تست پینگ سرورها و راهنمای بررسی نشت DNS.

![python-telegram-bot](https://img.shields.io/badge/python--telegram--bot-20+-2CA5E0.svg)
![License](https://img.shields.io/badge/license-MIT-green)

## ✨ امکانات

### 👤 کاربری
- 📡 دریافت لینک اشتراک (Subscription Link)
- 🖥 لیست سرورها با نام و پرچم کشور
- 🔳 تولید خودکار QR کد برای هر کانفیگ (اتصال با اسکن)
- 📋 کپی مستقیم متن کانفیگ
- 📶 تست دسترسی/پینگ زنده‌ی هر سرور
- 🛡️ راهنمای بررسی نشت DNS
- 📥 لینک دانلود کلاینت‌های رسمی برای هر پلتفرم (Android/iOS/Windows/macOS/Linux/Router)
- ❓ بخش سوالات متداول

### 🛠️ پنل مدیریت (فقط ادمین)
- 📊 آمار ربات (تعداد کاربران، پیام‌ها، آپ‌تایم)
- 🧩 لیست/افزودن/حذف کانفیگ‌ها
- 📣 ارسال پیام همگانی به همه‌ی کاربران
- 📤 خروجی گرفتن از لیست کاربران

## 📋 پیش‌نیازها

- Python نسخه‌ی ۳.۹ یا بالاتر

## ⚙️ نصب و راه‌اندازی

### گام ۱: نصب وابستگی‌ها
```bash
pip install -r requirements.txt
```

### گام ۲: تنظیم توکن و ادمین
در فایل `main.py`:
```python
TOKEN = os.getenv("BOT_TOKEN", "YOUR_BOT_TOKEN_HERE")   # یا مستقیم توکن رو اینجا بذار
ADMIN_ID = 123456789   # آیدی عددی تلگرام خودت
```
یا به‌جای ویرایش فایل، متغیر محیطی `BOT_TOKEN` رو ست کن.

### گام ۳: تنظیم لینک اشتراک و سرورها
مقدار `SUBSCRIPTION_LINK` و لیست `DEFAULT_CONFIGS` در `main.py` را با اطلاعات واقعی سرویس خودت جایگزین کن (کانفیگ‌های پیش‌فرض فعلی فقط نمونه‌ی تستی با دامنه‌ی `example.com` هستند و کار نمی‌کنند).

### گام ۴: اجرا
```bash
python main.py
```

با اولین اجرا، فایل‌های `users.json` و `configs.json` به‌صورت خودکار ساخته می‌شوند.

## 📖 دستورات

| دستور | توضیح |
|---|---|
| `/start` | نمایش منوی اصلی |
| `/admin` | نمایش پنل مدیریت (فقط ادمین) |

## ⚠️ نکته‌ی مهم

این ربات صرفاً یک **ابزار توزیع و مدیریت کانفیگ** است؛ خودش سرور VPN راه‌اندازی نمی‌کند. کانفیگ‌های نمونه‌ی داخل کد واقعی نیستند و باید با کانفیگ‌های سرور خودت جایگزین بشن.
