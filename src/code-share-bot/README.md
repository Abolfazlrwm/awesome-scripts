## 🚀 نصب و راه‌اندازی

### 1. پیش‌نیازها
```bash
Python 3.8+
Telegram Bot Token
```

### 2. نصب dependencies
```bash
pip install -r requirements.txt
```

### 3. تنظیمات اولیه
در فایل `bot.py` موارد زیر را تغییر دهید:

```python
# تنظیم توکن ربات
BOT_TOKEN = "YOUR_BOT_TOKEN_HERE"

# تنظیم آیدی ادمین‌ها
ADMIN_IDS = [123456789, 987654321]  # آیدی تلگرام خود را وارد کنید
```

### 4. اجرای ربات
```bash
python bot.py
```

## 📊 دیتابیس

ربات از SQLite استفاده می‌کند و شامل جداول زیر است:

### 👥 جدول کاربران (users)
- user_id (شناسه کاربر)
- username (نام کاربری)
- first_name (نام)
- last_name (نام خانوادگی)
- is_banned (وضعیت مسدودی)
- is_premium (وضعیت پریمیوم)
- join_date (تاریخ عضویت)
- last_activity (آخرین فعالیت)

### 📝 جدول کدها (snippets)
- id (شناسه منحصر به فرد)
- user_id (شناسه کاربر)
- title (عنوان)
- description (توضیحات)
- code (متن کد)
- language (زبان برنامه‌نویسی)
- is_private (خصوصی/عمومی)
- views (تعداد بازدید)
- likes (تعداد لایک)
- created_at (تاریخ ایجاد)

### ❤️ جدول لایک‌ها (likes)
- user_id (شناسه کاربر)
- snippet_id (شناسه کد)
- created_at (تاریخ لایک)
