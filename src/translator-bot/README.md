# 🌍 ربات مترجم متن (Translator Bot)

هر متنی برای ربات بفرستی، خودکار ترجمه‌ش می‌کنه. از یک API رایگان و بدون نیاز به ثبت‌نام استفاده می‌کند.

![Node.js](https://img.shields.io/badge/node.js-18+-339933.svg)
![node-telegram-bot-api](https://img.shields.io/badge/node--telegram--bot--api-0.66-2CA5E0.svg)
![License](https://img.shields.io/badge/license-MIT-green)

## ✨ امکانات

- 🌐 ترجمه‌ی خودکار پیام‌های عادی (تشخیص هوشمند جهت ترجمه: فارسی/عربی ↔ انگلیسی)
- 🎯 ترجمه به هر زبان دلخواه با `/tr [کد زبان] [متن]`
- ⚙️ تنظیم زبان مقصد پیش‌فرض برای هر کاربر با `/lang`
- 🆓 کاملاً رایگان — از API عمومی MyMemory استفاده می‌کند، نیازی به کلید API نیست

## 📋 پیش‌نیازها

- Node.js نسخه‌ی ۱۸ یا بالاتر (برای `fetch` داخلی)

## ⚙️ نصب و راه‌اندازی

### گام ۱: نصب وابستگی‌ها
```bash
npm install
```

### گام ۲: تنظیمات اولیه
فایل `bot.js` را باز کن و مقدار زیر را جایگزین کن:

| متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | توکن ربات از [@BotFather](https://t.me/BotFather) |

### گام ۳: اجرا
```bash
npm start
```

## 📖 دستورات

| دستور | توضیح |
|---|---|
| (فقط متن بفرست) | ترجمه‌ی خودکار |
| `/tr en سلام دنیا` | ترجمه به یک زبان خاص |
| `/lang en` | تنظیم زبان مقصد پیش‌فرض |
| `/langs` | لیست کدهای زبان پشتیبانی‌شده |

## ⚠️ محدودیت API رایگان

سرویس MyMemory برای استفاده‌ی رایگان روزانه محدودیت تعداد کاراکتر دارد (معمولاً حدود ۵۰۰۰ کاراکتر در روز برای هر IP). برای استفاده‌ی سنگین‌تر، می‌توانی در کد به یک سرویس ترجمه‌ی پولی (مثل Google Cloud Translation) سوییچ کنی.
