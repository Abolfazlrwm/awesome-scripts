# 🎮 ربات بازی دوز و مین‌یاب (Connect4 & Minesweeper)

ربات بازی گروهی تلگرام با دو بازی کلاسیک: دوز (Connect4) و مین‌یاب دو نفره، همراه با سیستم رنکینگ جهانی و گروهی، تاج هفتگی و لیدربورد.

![Python](https://img.shields.io/badge/python-3.8+-blue.svg)
![python-telegram-bot](https://img.shields.io/badge/python--telegram--bot-20+-2CA5E0.svg)
![License](https://img.shields.io/badge/license-MIT-green)

## ✨ امکانات

- 🎯 بازی دوز (Connect4) با تخته ۷×۶ و تشخیص خودکار برنده
- 💣 بازی مین‌یاب دو نفره رقابتی
- 🚀 شروع بازی در گروه با دستور یا در پیوی از طریق حالت اینلاین (Inline Mode)
- 🏆 سیستم امتیازدهی با رنکینگ جهانی و رنکینگ مخصوص هر گروه
- 📊 آمار شخصی هر کاربر (برد / باخت / مساوی / امتیاز / رتبه)
- 👑 مدال و تاج هفتگی برای برترین بازیکنان
- 🔒 عضویت اجباری در کانال(های) دلخواه قبل از بازی
- 📢 مدیریت کانال‌های جوین اجباری از پنل ادمین
- 🎖 ترفیع و عزل کاربران در سطح گروه (دسترسی بازی بدون نیاز به ادمین بودن)
- 🛠 پنل ادمین کامل: ارسال همگانی، فوروارد همگانی، آمار کلی
- 🏅 توزیع خودکار جوایز و تاج در پایان هر هفته
- ⏱ تایمر ثانیه‌ای برای هر نوبت بازی

## 📋 پیش‌نیازها

- Python نسخه‌ی ۳.۸ یا بالاتر
- کتابخانه‌ی `python-telegram-bot`

## ⚙️ نصب و راه‌اندازی

### گام ۱: نصب وابستگی‌ها
```bash
pip install -r requirements.txt

### گام ۲: تنظیمات اولیه
فایل `bot.py` را باز کن و مقادیر زیر را تنظیم کن:

| متغیر | توضیح |
|---|---|
| `TOKEN` | توکن ربات از [@BotFather](https://t.me/BotFather) |
| `ADMIN_ID` | آیدی عددی ادمین اصلی از [@userinfobot](https://t.me/userinfobot) |

### گام ۳: اجرا
```bash
python bot.py

پایگاه‌داده (`game_bot.db`) به‌صورت خودکار ساخته می‌شود.

### گام ۴: افزودن کانال جوین اجباری (اختیاری)
از دستور `/admin` در پیوی ربات (فقط برای ادمین) وارد پنل شو و از بخش «افزودن کانال» کانال دلخواه را اضافه کن.
